# PcaStockReduce.py 코드 설명

> 한 줄 요약: 50개 주식의 6가지 복잡한 정보를 PCA라는 방법으로 핵심 2가지 정보만 뽑아내서 2D 지도로 그립니다.

---

## 이 코드가 하는 일

50개의 주식마다 PER, PBR, ROE 같은 6가지 숫자가 있어요. 이걸 한꺼번에 머릿속에 그리기가 너무 어렵죠. PCA는 이 6가지 정보 중에서 "가장 중요한 방향 2가지"만 골라서 2D 지도(xy 좌표)로 표현해줘요. 마치 사진처럼 3D 세상을 2D 종이에 담아도 전체적인 모습은 알 수 있는 것처럼, PCA도 중요한 정보를 최대한 보존하면서 6차원을 2차원으로 줄여줘요.

## 코드 흐름 (단계별 설명)

### 1단계: 50개 주식의 6가지 지표 만들기
```python
n_stocks = 50
per = np.random.uniform(5, 25, n_stocks)       # 주가수익비율
pbr = per * np.random.uniform(0.05, 0.12, ...)  # 주가순자산비율
roe = np.random.uniform(5, 25, n_stocks)        # 자기자본이익률
volatility = np.random.uniform(0.1, 0.5, ...)   # 변동성
avg_return = roe * 0.3 + ...                    # 평균 수익률
volume = np.random.uniform(10, 500, n_stocks)   # 거래량
X = np.column_stack([per, pbr, roe, volatility, avg_return, volume])
# X.shape → (50, 6)
```
> 📌 **쉬운 설명:** 50개의 가상 주식 각각에 대해 6가지 정보를 랜덤으로 만들어요. `np.column_stack`으로 이것들을 합쳐 50행 6열짜리 표를 만들어요. 마치 50명 학생의 국어, 영어, 수학, 과학, 음악, 체육 점수 6가지가 있는 성적표와 같아요.

---

### 2단계: StandardScaler로 표준화
```python
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)
```
> 📌 **쉬운 설명:** 거래량은 10~500이고 PBR은 0.05~3처럼 숫자의 크기가 너무 달라요. 큰 숫자가 작은 숫자를 무시해버릴 수 있어서, 모든 지표를 "평균이 0, 표준편차가 1"이 되도록 통일해요. 마치 100점 만점인 시험과 10점 만점인 시험을 같은 기준으로 비교하려면 점수를 환산해야 하는 것과 같아요.

---

### 3단계: PCA 전체 분석 (6개 주성분 추출)
```python
pca_full = PCA()
pca_full.fit(X_scaled)
explained = pca_full.explained_variance_ratio_
cumulative = np.cumsum(explained)
```
> 📌 **쉬운 설명:** PCA는 6가지 지표 속에 숨어있는 "가장 중요한 방향"들을 차례로 찾아내요. 첫 번째 방향(PC1)이 정보를 가장 많이 담고, PC2가 두 번째로 많이 담아요. `explained_variance_ratio_`는 각 방향이 전체 정보의 몇 %를 담고 있는지 비율을 알려줘요.

---

### 4단계: 설명 분산 비율 출력
```python
for i, (e, c) in enumerate(zip(explained, cumulative)):
    bar = "█" * int(e * 40)
    print(f"PC{i+1}: {e*100:5.1f}%  누적={c*100:.1f}%  {bar}")
```
> 📌 **쉬운 설명:** 각 주성분(PC)이 전체 정보의 몇 %를 담고 있는지 막대 그래프 형태로 콘솔에 출력해요. PC1과 PC2 두 개만으로도 전체 정보의 상당 부분을 담을 수 있어요. 마치 6과목 중 국어와 수학 2과목만으로도 전체 학업 실력의 절반 이상을 파악할 수 있는 것과 같아요.

---

### 5단계: 6차원 → 2차원으로 압축
```python
pca2 = PCA(n_components=2)
X_2d = pca2.fit_transform(X_scaled)
# (50, 6) → (50, 2)로 압축
```
> 📌 **쉬운 설명:** 가장 중요한 방향 2개(PC1, PC2)만 남기고 나머지는 버려요. 이제 각 주식은 6개 숫자 대신 2개 숫자(PC1 점수, PC2 점수)만으로 표현돼요. 마치 50명의 학생을 6과목 점수 대신 "국수 종합 점수"와 "예체능 종합 점수" 2개로만 요약하는 것과 같아요.

---

### 6단계: 시각화 — 설명 분산 차트 + 2D 산점도
```python
ax1.bar(range(1, 7), explained, ...)          # 막대: 각 PC의 정보량
ax1.step(range(1, 7), cumulative, ...)        # 선: 누적 정보량
sc = ax2.scatter(X_2d[:, 0], X_2d[:, 1],
                 c=avg_return, cmap='RdYlGn') # 색깔: 수익률 높으면 초록
plt.savefig("../result/PcaStockReduce.png")
```
> 📌 **쉬운 설명:** 왼쪽 그래프는 각 주성분이 얼마나 중요한지 막대로 보여줘요. 오른쪽 그래프는 50개 주식을 2D 지도에 점으로 찍어요. 점의 색깔이 초록색이면 수익률이 높은 주식, 빨간색이면 낮은 주식이에요. 이 지도만 봐도 어떤 주식이 좋은지 한눈에 파악할 수 있어요!

## 핵심 개념 한눈에 보기

| 용어 | 쉬운 설명 |
|------|---------|
| **PCA (주성분 분석)** | 복잡한 여러 정보를 가장 중요한 방향 몇 개로 압축하는 방법이에요 |
| **주성분 (PC)** | PCA가 찾아낸 "가장 중요한 방향"이에요. PC1이 제일 중요하고, PC2가 그 다음이에요 |
| **설명 분산 비율** | 각 주성분이 전체 정보의 몇 %를 담고 있는지를 나타내는 숫자예요 |
| **누적 설명 분산** | PC1부터 순서대로 더해가면서 정보가 총 몇 %씩 쌓이는지를 나타내요 |
| **차원 (Dimension)** | 숫자의 개수예요. 6차원이면 6개 숫자, 2차원이면 2개 숫자로 표현된다는 뜻이에요 |
| **StandardScaler** | 데이터를 "평균 0, 표준편차 1"이 되도록 변환하는 도구예요 |
| **표준화 (Standardization)** | 크기가 서로 다른 변수들을 같은 기준으로 맞춰주는 것이에요 |
| **PER (주가수익비율)** | 주가가 회사의 이익에 비해 얼마나 비싼지를 나타내요. 낮을수록 저평가 |
| **PBR (주가순자산비율)** | 주가가 회사의 자산에 비해 얼마나 비싼지를 나타내요 |
| **ROE (자기자본이익률)** | 회사가 자기 돈으로 얼마나 이익을 냈는지 퍼센트로 나타내요. 높을수록 좋아요 |
| **변동성 (Volatility)** | 주가가 얼마나 들쭉날쭉한지예요. 높으면 위험하지만 기회도 커요 |
| **거래량 (Volume)** | 하루에 얼마나 많은 주식이 사고 팔렸는지를 나타내요 |
| **산점도 (Scatter Plot)** | 2D 좌표에 점을 찍어서 데이터를 표현하는 그래프예요 |
| **cmap='RdYlGn'** | Red-Yellow-Green 색지도예요. 낮은 값은 빨간색, 높은 값은 초록색으로 표현해요 |
| **fit_transform()** | 데이터를 분석하고(`fit`) 동시에 변환(`transform`)하는 함수예요 |
