# KMeansStockCluster.py 코드 설명

> 한 줄 요약: 60개의 가상 주식을 아무 정답 없이 컴퓨터 스스로 "성장주", "가치주", "방어주" 세 그룹으로 자동 분류하는 코드입니다.

---

## 이 코드가 하는 일

학교에서 선생님이 "키 순서대로 줄 서!" 라고 하면 아이들이 스스로 줄을 서듯이, 이 코드는 주식들에게 정답 라벨을 알려주지 않고도 비슷한 것끼리 자동으로 묶어줘요. 이것을 **비지도 학습**이라고 해요. "K-Means"는 주식들을 K개의 그룹으로 나누는 방법인데, 마치 동네 아이들을 여러 팀으로 나눌 때 비슷한 아이들끼리 묶어주는 것과 같아요.

각 주식의 "얼마나 많이 올랐는지(평균 수익률)"와 "얼마나 들쭉날쭉한지(변동성)" 두 가지만 보고, 3개 그룹(성장주·가치주·방어주)으로 나누고 그래프로 보여줘요.

## 코드 흐름 (단계별 설명)

### 1단계: 가상 주식 데이터 만들기

```python
returns_groups = [
    np.random.normal(0.15, 0.03, 20),   # 성장주: 수익 높음
    np.random.normal(0.07, 0.015, 20),  # 가치주: 수익 중간
    np.random.normal(0.04, 0.008, 20),  # 방어주: 수익 낮음
]
```

> 📌 **쉬운 설명:** 60개의 가상 주식을 만들어요. 실제로는 3종류가 섞여 있지만, 컴퓨터한테는 "정답"을 알려주지 않아요. 평균 수익률과 변동성(위험도) 두 가지 숫자만 줘요.

---

### 2단계: 데이터 표준화 (StandardScaler)

```python
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)
```

> 📌 **쉬운 설명:** 수익률은 0.04~0.15 사이, 변동성은 0.08~0.35 사이처럼 숫자 범위가 달라요. 이걸 그냥 쓰면 변동성이 거리 계산을 지배해버려요. 그래서 두 숫자를 모두 "평균 0, 편차 1" 기준으로 맞춰줘요. 마치 키는 cm로, 몸무게는 kg으로 재던 것을 모두 "평균 대비 몇 배"로 통일하는 것과 같아요.

---

### 3단계: K-Means 군집화 실행

```python
kmeans = KMeans(n_clusters=3, random_state=42, n_init=10)
labels = kmeans.fit_predict(X_scaled)
```

> 📌 **쉬운 설명:** 컴퓨터가 다음 과정을 반복해요.
> 1. 아무 데나 3개의 중심점(대표 선수)을 찍어요.
> 2. 각 주식을 가장 가까운 중심점의 팀에 넣어요.
> 3. 각 팀의 평균 위치로 중심점을 옮겨요.
> 4. 중심점이 더 이상 안 움직일 때까지 2~3번을 반복해요.

---

### 4단계: 군집 이름 붙이기

```python
centers_original = scaler.inverse_transform(kmeans.cluster_centers_)
order = np.argsort(centers_original[:, 0])[::-1]
label_names_map = {order[0]: '성장주', order[1]: '가치주', order[2]: '방어주'}
```

> 📌 **쉬운 설명:** K-Means는 그냥 "0번 그룹", "1번 그룹", "2번 그룹"이라고 숫자만 줘요. 그래서 수익률이 가장 높은 그룹을 "성장주", 중간은 "가치주", 낮은 것은 "방어주"라고 사람이 이름을 붙여줘요.

---

### 5단계: 군집별 통계 확인

```python
for name in ['성장주', '가치주', '방어주']:
    mask = np.array([n == name for n in label_names])
    print(f"{name}: {mask.sum()}종목 | 평균수익률={avg_returns[mask].mean():.3f}")
```

> 📌 **쉬운 설명:** 각 그룹에 몇 개 주식이 들어갔는지, 평균 수익률과 변동성이 어떻게 다른지 숫자로 확인해요.

---

ax.scatter(X[mask, 0], X[mask, 1], label=name, color=color, alpha=0.7)

## 핵심 개념 한눈에 보기

| 용어 | 쉬운 설명 |
|------|---------|
| 비지도 학습 | 정답 없이 데이터 스스로의 패턴을 찾는 방법이에요. 선생님 없이 혼자 공부하는 것과 같아요. |
| K-Means | 데이터를 K개의 그룹으로 나누는 군집화 방법이에요. K는 그룹 수예요. |
| 군집 (Cluster) | 비슷한 것끼리 모인 그룹이에요. 같은 팀이라고 생각하면 돼요. |
| 중심점 (Centroid) | 각 그룹의 평균 위치예요. 팀의 대표 선수처럼 그룹 전체를 대표해요. |
| 수렴 (Convergence) | 중심점이 더 이상 움직이지 않아 계산이 끝나는 것이에요. |
| 표준화 (StandardScaler) | 서로 다른 단위의 숫자들을 같은 기준으로 바꿔주는 것이에요. |
| 평균 수익률 | 주식이 평균적으로 얼마나 올랐는지를 나타내는 값이에요. |
| 변동성 | 주가가 얼마나 들쭉날쭉한지를 나타내요. 높을수록 위험하지만 기회도 커요. |
| 성장주 | 수익률 높고 변동성도 높은 주식 그룹이에요. 위험하지만 많이 오를 수 있어요. |
| 가치주 | 수익률과 변동성이 중간인 주식 그룹이에요. 균형이 잡혀 있어요. |
| 방어주 | 수익률 낮고 변동성도 낮은 주식 그룹이에요. 안전하지만 많이 오르지 않아요. |
| `n_init` | K-Means를 시작 위치를 바꿔서 여러 번 반복하는 횟수예요. 더 좋은 결과를 찾기 위해서예요. |
