## 이 코드가 하는 일

학교에서 시험을 보고 틀린 문제를 다시 공부해서 다음엔 더 잘 맞추는 것처럼, 이 코드의 신경망도 정답과 비교해서 틀린 만큼 스스로를 수정해요. 특별한 점은 PyTorch 같은 편리한 AI 도구를 쓰지 않고, NumPy만으로 신경망의 내부 계산(순전파, 역전파)을 직접 손으로 구현한다는 거예요. 마치 계산기를 쓰지 않고 손으로 덧셈 뺄셈을 직접 하는 것과 같아요. 과거 5일 주가로 다음 날 주가를 예측합니다.

## 코드 흐름 (단계별 설명)

### 1단계: 주가 데이터 준비
```python
df = yf.download('078935.KS', start='2020-01-01', ...)
prices = df['Close'].squeeze().dropna().values
```
> 📌 **쉬운 설명:** GS 주식의 2020년부터 오늘까지 종가(그날 마지막 가격)를 인터넷에서 가져와요. 가져올 수 없으면 규칙적으로 오르는 가짜 주가 220일치를 자동으로 만들어요.

---

### 2단계: 슬라이딩 윈도우 & 정규화
```python
window_size = 5
for i in range(days - window_size):
    X.append(prices[i:i + window_size])  # 5일치 입력
    y.append(prices[i + window_size])     # 6번째 날 정답
X_norm = (X - x_min) / (x_max - x_min)  # 0~1로 정규화
```
> 📌 **쉬운 설명:** 5칸짜리 창문을 하루씩 밀면서 (문제: 5일치 주가, 정답: 6번째 날 주가) 쌍을 만들어요. 그리고 모든 주가를 0~1 사이 숫자로 바꿔서 AI가 공평하게 비교할 수 있게 해줘요.

---

### 3단계: 가중치 초기화 (신경망 뇌 만들기)
```python
W1 = np.random.randn(input_size, hidden_size) * 0.1  # 5 × 8
b1 = np.zeros((1, hidden_size))
W2 = np.random.randn(hidden_size, output_size) * 0.1  # 8 × 1
b2 = np.zeros((1, output_size))
```
> 📌 **쉬운 설명:** 신경망의 "연결 고리(가중치)"를 아주 작은 랜덤 숫자로 시작해요. 신경망 구조는 5(입력) → 8(숨겨진 층) → 1(출력)이에요. 5일치 주가를 받아서 8개의 중간 뉴런을 거쳐 최종적으로 1개의 예측 주가를 냅니다.

---

### 4단계: 순전파 (앞으로 계산하기)
```python
z1 = X_train @ W1 + b1   # 입력층 → 은닉층 계산
a1 = sigmoid(z1)          # 활성화 함수 적용
y_pred = a1 @ W2 + b2     # 은닉층 → 출력층 계산
loss = np.mean((y_pred - y_train) ** 2)  # 오차 계산
```
> 📌 **쉬운 설명:** 데이터가 입력층에서 은닉층을 거쳐 출력층으로 쭉 흘러가요. 마치 음식 재료(주가)가 레시피(가중치)를 따라 요리되어 최종 음식(예측값)이 완성되는 것과 같아요. 마지막에 정답과 비교해서 얼마나 틀렸는지 오차를 계산해요.

---

### 5단계: 역전파 (뒤로 돌아가며 수정하기)
```python
d_y_pred = 2 * (y_pred - y_train) / len(y_train)
d_W2 = a1.T @ d_y_pred          # W2 수정량 계산
d_W1 = X_train.T @ d_z1         # W1 수정량 계산
W2 -= learning_rate * d_W2      # W2 업데이트
W1 -= learning_rate * d_W1      # W1 업데이트
```
> 📌 **쉬운 설명:** 틀린 이유를 출력층에서 입력층 방향으로 거꾸로 추적해요. 오답 노트에 "이 부분이 잘못됐어, 이만큼 고쳐야 해"라고 적는 것처럼, 각 가중치가 얼마나 틀렸는지 계산해서 조금씩 수정해요. 이걸 2000번 반복합니다!

---

### 6단계: Sigmoid 활성화 함수
```python
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_derivative(activated):
    return activated * (1 - activated)
```
> 📌 **쉬운 설명:** Sigmoid는 어떤 숫자든 0과 1 사이로 눌러주는 함수예요. 마치 아무리 강한 빛도 0~100% 밝기로만 표현하는 것과 같아요. 역전파에서는 이 함수의 기울기(derivative)를 이용해서 수정 방향을 계산해요.

---

### 7단계: 테스트 & 내일 주가 예측
```python
z1_test = X_test @ W1 + b1
a1_test = sigmoid(z1_test)
y_test_pred_norm = a1_test @ W2 + b2
y_test_pred = y_test_pred_norm * (y_max - y_min) + y_min  # 원래 값으로 되돌리기
mae = np.mean(np.abs(y_test_real - y_test_pred))
```
> 📌 **쉬운 설명:** 학습이 끝난 신경망에게 처음 보는 테스트 문제를 줘요. 예측한 값을 0~1에서 원래 원 단위로 돌려놓고, 실제 주가와 얼마나 차이 나는지(MAE) 계산해요. 마지막으로 가장 최근 5일 데이터를 넣어 내일 주가를 예측합니다.

## 핵심 개념 한눈에 보기

| 용어 | 쉬운 설명 |
|------|---------|
| **신경망 (Neural Network)** | 사람 뇌의 뉴런을 흉내낸 AI 구조예요. 숫자가 여러 층을 거치며 처리돼요 |
| **가중치 (Weight, W)** | 뉴런들 사이의 연결 강도예요. 학습하면서 이 숫자가 조금씩 수정돼요 |
| **편향 (Bias, b)** | 가중치 외에 더하는 기본값이에요. 예측을 더 유연하게 만들어줘요 |
| **순전파 (Forward Pass)** | 데이터가 입력층 → 은닉층 → 출력층 방향으로 흘러가는 계산이에요 |
| **역전파 (Backpropagation)** | 오차를 출력층에서 입력층 방향으로 거꾸로 전달해서 가중치를 수정해요 |
| **은닉층 (Hidden Layer)** | 입력과 출력 사이에 있는 중간 계산 층이에요. 이 코드에서는 8개 뉴런이 있어요 |
| **Sigmoid 함수** | 어떤 숫자든 0~1 사이로 변환해주는 함수예요. S자 모양 곡선이에요 |
| **학습률 (Learning Rate)** | 가중치를 얼마나 크게 수정할지 정하는 숫자예요. 너무 크면 불안정하고, 너무 작으면 느려요 |
| **에폭 (Epoch)** | 전체 데이터를 처음부터 끝까지 한 번 학습하는 단위예요 |
| **MSE 손실** | (예측값 - 정답)²의 평균이에요. 틀릴수록 숫자가 커져요 |
| **MAE** | 예측이 평균적으로 얼마나 틀렸는지 원 단위로 나타내는 점수예요 |
| **Min-Max 정규화** | 주가처럼 큰 숫자를 0~1 사이로 작게 만드는 기술이에요 |
| **슬라이딩 윈도우** | 창문을 한 칸씩 옆으로 밀면서 (입력, 정답) 쌍을 만드는 방법이에요 |
| **편미분 (Gradient)** | 가중치 하나를 조금 바꾸면 손실이 얼마나 변하는지를 나타내는 값이에요 |
