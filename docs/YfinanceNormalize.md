## 이 코드가 하는 일

여러 학생의 키를 비교할 때, 단위가 cm인 사람과 m인 사람을 그냥 비교하면 엉터리 결과가 나옵니다. AI도 마찬가지로 숫자의 크기가 제각각이면 제대로 공부하지 못합니다.
이 코드는 주식 가격을 AI에게 먹이기 좋은 형태로 바꾸는 세 가지 요리법(Min-Max, Z-점수, 로그수익률)을 보여주고, 각 방법의 결과를 그림으로 비교합니다.
마치 체육 시간에 모든 학생의 키를 100점 만점 점수로 환산하거나, 평균보다 얼마나 큰지로 표현하는 것과 똑같은 원리입니다.

df = yf.download('078935.KS', start='2020-01-01', ...)

---

### 2단계: 세 가지 정규화 함수 만들기

#### Min-Max 정규화
```python
def minmax_normalize(series):
    return (series - s_min) / (s_max - s_min + 1e-8), s_min, s_max
```
> 📌 **쉬운 설명:** 역대 가장 낮은 가격을 0, 역대 가장 높은 가격을 1로 바꾸고 나머지는 그 사이 값으로 변환합니다. 예를 들어 키가 120cm~180cm인 반에서 150cm인 학생은 0.5(중간)가 됩니다. 결과는 항상 0과 1 사이입니다.

#### Z-점수 정규화
```python
def zscore_normalize(series):
    return (series - mean) / (std + 1e-8), mean, std
```
> 📌 **쉬운 설명:** 반 평균과의 차이를 "표준편차"라는 단위로 표현합니다. 0은 평균, +1은 평균보다 한 칸 위, -1은 평균보다 한 칸 아래를 뜻합니다. 시험 점수를 "전교 평균보다 몇 점 높다"로 표현하는 것과 같습니다.

#### 로그 수익률
```python
def log_return(series):
    return np.log(series / series.shift(1)).dropna()
```
> 📌 **쉬운 설명:** 어제 가격과 오늘 가격의 비율을 로그(log)로 변환합니다. "오늘 주가가 어제보다 몇 % 달라졌나"를 나타내는데, 로그를 쓰면 수학적으로 더 다루기 편해집니다. `shift(1)`은 어제 가격을 가져오는 것입니다.

### 3단계: 모든 종목에 정규화 적용하기
```python
for ticker, prices in raw_data.items():
    mm, mn, mx    = minmax_normalize(prices)
    zs, mu, sigma = zscore_normalize(prices)
    lr            = log_return(prices)
```
> 📌 **쉬운 설명:** 준비한 세 가지 요리법을 실제 데이터에 차례로 적용합니다. 결과를 `normalized_results`라는 큰 바구니에 담아둡니다.

---

### 4단계: Min-Max 역정규화 확인
```python
reconstructed = r['minmax'] * (mx - mn) + mn
max_err = (reconstructed - r['prices']).abs().max()
```
> 📌 **쉬운 설명:** 0~1로 바꿨던 가격을 다시 원래 가격으로 되돌려봅니다. 되돌린 값과 원래 값의 차이(오차)가 거의 0이어야 합니다. 마치 요리 재료를 잘게 썰었다가 다시 원래 크기로 복원할 수 있는지 확인하는 것입니다.

---

### 5단계: 로그수익률 통계 출력
```python
print(f"평균={lr.mean():.5f}  σ={lr.std():.5f}  최소={lr.min():.4f}  최대={lr.max():.4f}")
```
> 📌 **쉬운 설명:** 변환된 로그수익률의 특성(평균, 표준편차, 최솟값, 최댓값)을 화면에 출력합니다. 평균이 0에 가깝고, 최솟값과 최댓값이 대칭에 가까울수록 좋은 신호입니다.

## 핵심 개념 한눈에 보기

| 용어 | 쉬운 설명 |
|------|---------|
| **정규화(Normalization)** | 서로 다른 크기의 숫자들을 같은 기준으로 맞추는 것. AI가 공평하게 학습하게 해줌 |
| **Min-Max 정규화** | 가장 작은 값=0, 가장 큰 값=1로 바꾸고 나머지는 그 사이로 조정 |
| **Z-점수 정규화** | 평균을 0, 표준편차를 1로 맞추는 방법. 이상한 값(이상치)에 덜 흔들림 |
| **로그 수익률** | 하루하루 주가 변화를 로그를 이용해 표현하는 방법. 더하고 빼기가 쉬워짐 |
| **역정규화** | 정규화했던 것을 다시 원래 값으로 되돌리는 것 |
| **표준편차(σ)** | 숫자들이 평균에서 얼마나 넓게 퍼져있는지를 나타내는 값 |
| **이상치** | 다른 값들과 동떨어진 극단적으로 크거나 작은 값 |
| **히스토그램** | 데이터가 어떤 값에 얼마나 몰려있는지 막대그래프로 보여주는 것 |
| **정상성(Stationarity)** | 시간이 지나도 평균과 분산이 크게 변하지 않는 안정적인 상태 |
| **가법적(Additive)** | 여러 기간의 수익률을 그냥 더해서 전체 수익률을 구할 수 있는 성질 |
| `shift(1)` | pandas에서 하루 전 데이터를 가져오는 방법 |
| `dropna()` | 계산할 수 없는 빈 값(NaN)을 제거하는 것 |
| **1e-8** | 0.00000001이라는 아주 작은 숫자. 0으로 나누는 오류를 막기 위해 더함 |
| **yfinance** | 야후 파이낸스에서 주식 데이터를 무료로 가져올 수 있는 파이썬 도구 |
| `auto_adjust=True` | 주식 분할이나 배당 등을 자동으로 보정해서 가져오는 옵션 |
