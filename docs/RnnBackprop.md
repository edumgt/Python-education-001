## 이 코드가 하는 일

마치 선생님이 수업 내용을 칠판에 적으면서 앞에서 배운 내용을 계속 기억하는 것처럼, RNN(순환 신경망)도 오늘 주가를 볼 때 어제, 그제 주가까지 함께 기억합니다. 이 코드는 그 기억 장치를 **직접** 수식으로 만들고, 과거 10일치 주가 변화율을 보고서 내일 주가가 오를지(1) 내릴지(0) 맞히도록 훈련시킵니다. 훈련이 끝나면 얼마나 잘 맞혔는지 그림으로 그려서 저장합니다.

## 코드 흐름 (단계별 설명)

### 1단계: 주가 데이터 준비하기
```python
returns = np.diff(prices) / prices[:-1]
X_list.append(returns[i:i + seq_len])
y_list.append(1.0 if returns[i + seq_len] > 0 else 0.0)
```
> 📌 **쉬운 설명:** 주가 자체 대신 "오늘 얼마나 올랐나(수익률)"를 계산합니다. 그리고 연속 10일치 수익률을 묶어서 하나의 문제로 만들고, 11번째 날이 오르면 정답을 1, 내리면 0으로 적어 둡니다. 마치 시험 문제지(X)와 정답지(y)를 만드는 것과 같습니다.

---

### 2단계: RNN 가중치(뇌의 시냅스) 초기화
```python
Wx = np.random.randn(input_size,  hidden_size) * scale
Wh = np.random.randn(hidden_size, hidden_size) * scale
Wy = np.random.randn(hidden_size, output_size) * scale
```
> 📌 **쉬운 설명:** RNN에는 세 종류의 가중치가 있습니다. `Wx`는 오늘 입력을 처리하는 시냅스, `Wh`는 **어제 기억을 오늘로 전달하는 시냅스**(RNN에서 가장 중요!), `Wy`는 기억을 바탕으로 예측값을 만드는 시냅스입니다. 처음에는 작은 무작위 숫자로 시작합니다.

---

### 3단계: 앞으로 계산하기 (순전파)
```python
def forward_rnn(x_seq, h0):
    for t in range(len(x_seq)):
        zt = xt @ Wx + h @ Wh + bh   # 선형 변환
        h  = np.tanh(zt)              # 활성화 (tanh)
    y_pred = sigmoid(hs[-1] @ Wy + by)
    return y_pred, hs, xs, zs
```
> 📌 **쉬운 설명:** 10일치 수익률을 하나씩 읽으면서 매번 "지금까지의 기억(h)"을 새로운 내용으로 업데이트합니다. 마지막 날까지 읽고 나면, 지금까지의 기억을 가지고 내일 오를 확률을 계산합니다. `tanh`는 기억 값이 너무 커지거나 작아지지 않게 -1과 1 사이로 눌러주는 역할을 합니다.

---

### 4단계: 틀린 부분을 고치기 (BPTT 역전파)
```python
def bptt(x_seq, y_true, hs, xs, zs):
    for t in reversed(range(len(x_seq))):  # 시간 역방향
        dh = dh_next * (1 - hs[t] ** 2)   # tanh 미분
        dWx += xs[t].T @ dh
        dh_next = dh @ Wh.T               # 이전 시점으로 전파
    Wx -= lr * dWx
```
> 📌 **쉬운 설명:** 정답과 비교해서 틀린 만큼 가중치를 조금씩 수정합니다. 시험에서 틀린 문제를 거꾸로 다시 풀어보는 것과 같습니다. 시간을 **거꾸로** 거슬러 올라가며 각 날짜에서의 오류를 고치기 때문에 "BPTT(시간을 통한 역전파)"라고 부릅니다.

---

### 5단계: 반복 학습 (600번)
```python
for epoch in range(epochs):
    for i in idx:
        y_pred, hs, xs, zs = forward_rnn(x_seq, np.zeros((1, hidden_size)))
        bptt(x_seq, y_true, hs, xs, zs)
```
> 📌 **쉬운 설명:** 같은 문제를 600번 반복해서 풀고, 매번 틀린 부분을 고칩니다. 반복할수록 손실(오류)이 줄어들며 점점 잘 맞히게 됩니다.

## 핵심 개념 한눈에 보기

| 용어 | 쉬운 설명 |
|------|---------|
| **RNN (순환 신경망)** | 이전 결과를 다음 계산에 다시 넣어서 "기억"을 만드는 신경망. 마치 릴레이 달리기에서 앞 주자의 바통을 다음 주자에게 전달하는 것과 같습니다 |
| **은닉 상태 (h)** | RNN이 지금까지 읽은 내용을 저장하는 "기억 공간". 각 날짜마다 업데이트됩니다 |
| **BPTT** | BackPropagation Through Time의 줄임말. 오류를 시간 순서를 거슬러 올라가며 수정하는 방법 |
| **tanh** | 어떤 숫자든 -1과 1 사이로 눌러주는 함수. 기억값이 폭발하지 않도록 막아줍니다 |
| **sigmoid** | 어떤 숫자든 0과 1 사이로 바꿔주는 함수. 확률(오를 가능성이 몇 %)처럼 표현할 때 씁니다 |
| **손실 (Loss)** | 예측이 정답과 얼마나 다른지를 나타내는 점수. 낮을수록 잘 맞힌 것입니다 |
| **학습률 (lr)** | 한 번에 가중치를 얼마나 많이 수정할지 결정하는 값. 너무 크면 엉뚱한 방향으로 튀고, 너무 작으면 천천히 배웁니다 |
| **에폭 (epoch)** | 전체 학습 데이터를 한 번 다 훈련한 횟수. 600 에폭 = 같은 데이터를 600번 반복 학습 |
| **수익률** | (오늘 주가 - 어제 주가) ÷ 어제 주가. 주가가 얼마나 변했는지 비율로 나타낸 것 |
| **BCE Loss** | Binary Cross Entropy Loss. 오르거나(1) 내리거나(0) 둘 중 하나를 맞힐 때 쓰는 오류 측정 방법 |
| **기울기 클리핑** | 기울기(수정량)가 너무 커지면 -5~5 사이로 잘라내는 것. 가중치가 한 번에 너무 많이 바뀌어 망가지는 것을 막습니다 |
| **서포트 벡터** | (RNN과 직접 관련은 없지만) 결정 경계에 가장 가까운 데이터 점들 |
