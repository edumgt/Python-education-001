## 이 코드가 하는 일

우리가 시험공부를 할 때 지난 수업 내용을 기억하면서 공부하는 것처럼, LSTM은 주가의 흐름을 기억하면서 다음 날 주가를 예측해요. 마치 일기장에서 지난 20일치 날씨 기록을 읽고 내일 날씨를 맞추는 것과 비슷해요. PyTorch라는 도구를 사용해서 이 똑똑한 AI를 만들고, 실제로 학습시킨 뒤 예측 결과를 그래프로 그려줍니다.

## 코드 흐름 (단계별 설명)

### 1단계: 주가 데이터 준비
```python
df = yf.download(TICKER, start='2020-01-01', ...)
prices = df['Close'].squeeze().dropna().values
```
> 📌 **쉬운 설명:** 인터넷에서 GS 주식(종목코드 078935.KS)의 2020년부터 오늘까지 매일 종가(그날 마지막 가격)를 가져와요. 인터넷이 안 되면 컴퓨터가 가상의 주가 데이터를 직접 만들어줍니다.

---

### 2단계: 슬라이딩 윈도우로 데이터 만들기
```python
SEQ_LEN = 20
for i in range(len(norm) - SEQ_LEN):
    X_list.append(norm[i:i + SEQ_LEN])   # 입력: 20일치
    y_list.append(norm[i + SEQ_LEN])      # 정답: 21번째 날
```
> 📌 **쉬운 설명:** 마치 20칸짜리 창문을 하루씩 오른쪽으로 밀면서, 창문 안에 보이는 20일 주가를 입력으로, 창문 바로 다음 날 주가를 정답으로 묶어요. 이렇게 수백 쌍의 (문제, 정답) 세트가 만들어집니다.

---

### 3단계: Min-Max 정규화 (숫자 크기 맞추기)
```python
p_min, p_max = prices.min(), prices.max()
norm = (prices - p_min) / (p_max - p_min + 1e-8)
```
> 📌 **쉬운 설명:** 주가가 어떤 회사는 1만원, 어떤 회사는 100만원일 수 있어요. AI가 공평하게 비교할 수 있도록 모든 숫자를 0과 1 사이로 바꿔줘요. 마치 서로 다른 단위의 거리를 모두 "100점 만점" 기준으로 환산하는 것과 같아요.

---

### 4단계: LSTM 모델 만들기
```python
class LSTMStock(nn.Module):
    def __init__(self):
        self.lstm = nn.LSTM(input_size=1, hidden_size=32, num_layers=2)
        self.dropout = nn.Dropout(0.2)
        self.fc = nn.Linear(32, 1)
```
> 📌 **쉬운 설명:** LSTM 모델의 구조를 설계해요. 주가 데이터가 들어오면 → LSTM 층 2개를 거쳐 패턴을 학습하고 → Dropout으로 과한 암기를 막고 → 마지막 선형층에서 주가 1개를 출력해요. 마치 공부 → 쉬기 → 시험 답 쓰기 순서와 같아요.

---

### 5단계: 학습 루프 (반복 공부)
```python
for epoch in range(EPOCHS):           # 300번 반복
    pred = model(xb)                  # 예측
    loss = criterion(pred, yb)        # 얼마나 틀렸는지 계산
    loss.backward()                   # 역전파: 어디서 틀렸는지 찾기
    optimizer.step()                  # 가중치 조금씩 수정
```
> 📌 **쉬운 설명:** AI가 문제를 풀고 → 정답과 비교해서 점수를 매기고 → 왜 틀렸는지 분석하고 → 다음엔 더 잘 풀도록 뇌를 조금 수정해요. 이걸 300번 반복하면 점점 실력이 올라가요!

---

### 6단계: 테스트 및 내일 주가 예측
```python
model.eval()
with torch.no_grad():
    pred_norm = model(X_test).cpu().numpy().flatten()
next_price = next_norm * (p_max - p_min) + p_min
```
> 📌 **쉬운 설명:** 학습이 끝나면 AI가 한 번도 본 적 없는 테스트 데이터로 실력을 검사해요. 그리고 가장 최근 20일 주가를 입력하면 내일 주가를 예측해줘요. 정규화했던 숫자를 다시 원래 가격으로 되돌려서 "내일 예상 주가: XX원"으로 알려줍니다.

## 핵심 개념 한눈에 보기

| 용어 | 쉬운 설명 |
|------|---------|
| **LSTM** | "오래 기억하는 신경망"이에요. 일반 AI는 금방 잊어버리지만, LSTM은 오래된 정보도 기억할 수 있어요 |
| **셀 상태(Cell State)** | LSTM의 장기 기억 공간이에요. 마치 중요한 내용을 적어두는 노트북 같아요 |
| **망각 게이트** | "이 기억은 이제 필요 없어"하고 잊을지 말지 결정하는 문이에요 |
| **입력 게이트** | "이 새 정보를 기억할까?"하고 새 정보를 받아들일지 결정하는 문이에요 |
| **출력 게이트** | "지금 이 기억 중에 어느 것을 내보낼까?"하고 결정하는 문이에요 |
| **슬라이딩 윈도우** | 창문을 하루씩 옆으로 밀면서 데이터를 자르는 방법이에요 |
| **정규화 (Min-Max)** | 크고 작은 숫자들을 모두 0~1 사이로 고르게 만드는 것이에요 |
| **에폭 (Epoch)** | AI가 전체 문제를 처음부터 끝까지 한 번 공부하는 단위예요 |
| **배치 (Batch)** | 한 번에 공부하는 문제 묶음이에요. 32개씩 나눠서 공부해요 |
| **손실 (Loss / MSE)** | AI가 얼마나 틀렸는지 나타내는 점수예요. 낮을수록 잘 맞춘 거예요 |
| **역전파 (Backprop)** | 틀린 부분을 거꾸로 추적해서 어디가 문제인지 찾는 방법이에요 |
| **Adam 옵티마이저** | 가중치를 얼마나 수정할지 자동으로 계산해주는 똑똑한 도우미예요 |
| **Dropout** | 학습 중 뉴런을 일부러 꺼서 AI가 너무 답을 외우지 않게 해요 |
| **MAE** | 예측값이 평균적으로 얼마나 틀렸는지 (원 단위)를 나타내요 |
| **RMSE** | MAE와 비슷하지만 큰 오차를 더 크게 벌칙 주는 점수예요 |
| **PyTorch** | 구글과 페이스북이 만든 AI 개발 도구 상자예요 |
