# HeatmapRiskMask.py 코드 설명

> 한 줄 요약: 20일 × 20종목의 주가 수익률 데이터에서 크게 오르내린 "위험한 날"을 자동으로 찾아 색으로 표시하는 코드예요.

---

## 이 코드가 하는 일

마치 지도에서 위험 지역을 빨갛게 칠하듯, 이 코드는 많은 종목의 주가 데이터를 표(행렬)로 만들고 "어떤 날, 어떤 종목이 크게 움직였는지"를 색깔로 표시해요.
"±2%보다 크게 움직인 날"을 위험으로 정의하고, 그 위치만 흰색으로 표시하는 마스크(가리개)를 만들어요.
마지막으로 위험 구간을 더 진한 색으로 강조한 히트맵을 그려서 한눈에 볼 수 있게 저장해요.

## 코드 흐름 (단계별 설명)

### 1단계: 수익률 데이터 행렬 만들기
```python
np.random.seed(42)
returns_map = np.random.normal(loc=0.1, scale=1.2, size=(20, 20))
```
> **쉬운 설명:** 20일 × 20종목의 수익률 표를 만들어요. `np.random.normal(loc=0.1, scale=1.2)`는 "평균 0.1%, 흔들림 1.2%"인 수익률을 랜덤으로 생성해요. 결과는 숫자 400개(20×20)가 가득 찬 표예요. 엑셀 표처럼 세로(행)는 날짜, 가로(열)는 종목 번호라고 생각하면 돼요.

---

### 2단계: 위험 구간 마스크 만들기
```python
risk_mask = (np.abs(returns_map) > 2.0).astype(int)
risk_count = risk_mask.sum()
```
> **쉬운 설명:** 수익률의 절대값이 2.0%를 넘으면 "위험(1)", 그 이하면 "안전(0)"으로 표시하는 표를 만들어요. `np.abs()`는 절대값을 구하는 함수예요. 예를 들어 +2.5%나 -3.0%는 모두 위험이지만, +1.0%나 -0.5%는 안전이에요. 이 마스크를 보면 어느 날짜·종목이 위험했는지 한눈에 알 수 있어요.

---

### 3단계: 위험 구간 값 강조하기
```python
highlighted = returns_map.copy()
highlighted[risk_mask == 1] = np.sign(highlighted[risk_mask == 1]) * 3.0
```
> **쉬운 설명:** 위험한 칸들의 수익률 값을 ±3.0으로 강제로 바꿔요. `np.sign()`은 양수면 +1, 음수면 -1을 반환하는 함수예요. 즉, 위험 구간은 무조건 +3.0 또는 -3.0으로 바꿔서, 색깔 히트맵에서 더 진하게 보이게 만들어요. 지도에서 위험 지역을 더 진한 빨강으로 표시하는 것과 같아요.

---

### 4단계: 3가지 히트맵 그리기
```python
fig, axs = plt.subplots(1, 3, figsize=(12, 4))

axs[0].imshow(returns_map, cmap='RdYlGn')   # 원본 수익률
axs[1].imshow(risk_mask, cmap='gray')        # 이진 위험 마스크
axs[2].imshow(highlighted, cmap='RdYlGn')   # 강조된 히트맵
```
> **쉬운 설명:** 세 개의 그림을 나란히 그려요.
> - 첫 번째(원본): 수익률이 높으면 초록, 낮으면 빨강으로 표시한 원본 색깔 표
> - 두 번째(마스크): 위험한 칸은 흰색, 안전한 칸은 검정으로 표시한 단순한 흑백 표
> - 세 번째(강조): 위험 구간이 더 진하게 표시된 색깔 표
> `cmap='RdYlGn'`은 빨강-노랑-초록 색깔표(colormap)를 의미해요.

---

### 5단계: 화살표 어노테이션 추가하기
```python
risk_positions = np.argwhere(risk_mask == 1)
row_r, col_r = risk_positions[0]
axs[1].annotate("이 날 이 종목이\n±2% 이상 크게\n움직였어요",
                xy=(col_r, row_r),
                xytext=(col_r + 5, row_r - 5),
                arrowprops=dict(arrowstyle='->'))
```
> **쉬운 설명:** 마스크 그림에서 위험한 칸(흰색) 중 첫 번째 위치를 찾아서 화살표로 가리키며 설명을 붙여요. `np.argwhere()`는 조건이 맞는 칸의 위치(행, 열)를 찾아주는 함수예요.

---

### 6단계: 그래프 저장
```python
plt.tight_layout(rect=[0, 0, 1, 0.95])
plt.savefig("../result/HeatmapRiskMask.png", dpi=150, bbox_inches="tight")
```
> **쉬운 설명:** 세 그림을 PNG 이미지 파일로 저장해요. `tight_layout`은 그림들이 겹치지 않게 간격을 자동으로 조절해주고, `dpi=150`은 이미지를 선명하게 저장하는 설정이에요.

## 핵심 개념 한눈에 보기

| 용어 | 쉬운 설명 |
|------|---------|
| 히트맵 (Heatmap) | 숫자 표를 색깔로 바꿔서 한눈에 크고 작음을 보여주는 그림 |
| 수익률 | 주가 변화를 퍼센트(%)로 나타낸 것. 양수는 이익, 음수는 손실 |
| 행렬 (Matrix) | 숫자를 가로·세로로 정렬한 표. 이 코드에서는 20행 × 20열 = 400칸 |
| 마스크 (Mask) | 특정 조건에 맞는 칸만 1(흰색), 나머지는 0(검정)으로 표시하는 이진 필터 |
| 절대값 | 음수·양수 부호를 무시한 크기. |-3| = 3, |+3| = 3 |
| np.abs() | 숫자 배열의 절대값을 구하는 NumPy 함수 |
| np.sign() | 양수면 +1, 0이면 0, 음수면 -1을 반환하는 함수 |
| np.argwhere() | 조건이 참인 칸들의 위치(행 번호, 열 번호)를 찾아주는 함수 |
| cmap | 숫자를 색깔로 바꾸는 색상표. 'RdYlGn'은 빨강-노랑-초록 그라데이션 |
| imshow | 숫자 행렬을 색깔 이미지로 그려주는 matplotlib 함수 |
| annotate | 그래프에 텍스트와 화살표로 설명을 덧붙이는 matplotlib 기능 |
| np.random.normal | 정규분포(종모양 분포)에서 랜덤 숫자를 뽑는 함수. loc=평균, scale=흔들림 |
| subplots(1, 3) | 1행 3열로 그래프 칸을 나누는 함수. 세 그림을 나란히 그릴 수 있어요 |
| tight_layout | 여러 그래프가 겹치지 않게 자동으로 간격을 조절해주는 함수 |
| dpi | 이미지 해상도(점의 밀도). 클수록 더 선명해요. 150이면 꽤 선명한 수준 |
