# LinearRegressionReturn.py 코드 설명

> 한 줄 요약: 최근 5일간의 주가 수익률 변화를 보고, 앞으로 5일간의 누적 수익률을 선형 회귀로 예측하는 코드입니다.

---

## 이 코드가 하는 일

날씨 예보처럼, 지난 며칠간의 날씨 패턴을 보고 내일 날씨를 예측할 수 있어요. 이 코드도 같은 방식으로, **지난 5일 동안 주가가 어떻게 변했는지**를 보고 **앞으로 5일 동안 얼마나 오르내릴지**를 예측해요.

인터넷에서 실제 주식 데이터(GS피앤엘, 종목코드 078935.KS)를 내려받아서 사용하고, 만약 인터넷이 안 되면 가짜 데이터를 만들어서 사용해요. 예측 결과는 그래프로 저장해서 "이 날에는 주가가 이 정도일 것 같다"고 눈으로 볼 수 있게 해줘요.

## 코드 흐름 (단계별 설명)

### 1단계: 실제 주가 데이터 불러오기

```python
TICKER = '078935.KS'
df = yf.download(TICKER, start='2020-01-01', end=date.today().isoformat(), ...)
prices = close_series.values.flatten().astype(np.float64)
```

> 📌 **쉬운 설명:** 야후 파이낸스라는 사이트에서 GS피앤엘 주식의 2020년부터 오늘까지의 종가(그날 마지막 거래 가격)를 내려받아요. 인터넷 연결이 안 되면 자동으로 비슷한 가짜 데이터를 만들어서 계속 진행해요.

---

### 2단계: 슬라이딩 윈도우로 데이터 만들기

```python
LOOK_BACK = 5   # 이전 5일치로 예측
HORIZON   = 5   # 다음 5일치를 예측

for i in range(LOOK_BACK, len(returns) - HORIZON):
    X_list.append(returns[i - LOOK_BACK:i])      # 이전 5일 수익률
    y_list.append(returns[i:i + HORIZON].sum())  # 다음 5일 누적 수익률
```

> 📌 **쉬운 설명:** 긴 수익률 데이터를 5일짜리 창으로 훑어가며 "이전 5일 → 다음 5일" 짝을 수백 개 만들어요. 예를 들어 1~5일을 보고 6~10일을 예측, 2~6일을 보고 7~11일을 예측하는 식이에요. 이것을 **슬라이딩 윈도우**라고 해요. 마치 자로 종이를 5칸씩 밀면서 재는 것처럼요.

---

### 3단계: 선형 회귀 학습

```python
model = LinearRegression()
model.fit(X, y)
r2 = 1 - ss_res / ss_tot
print(f"R² = {r2:.4f}")
```

> 📌 **쉬운 설명:** "5일 수익률 → 다음 5일 수익률" 패턴을 배워요. R² 점수는 모델이 얼마나 잘 예측하는지 0~1 사이로 나타내는데, 1에 가까울수록 좋아요. 주식은 랜덤하기 때문에 완벽한 예측은 불가능하지만, 1일치만 쓸 때보다 5일치를 쓰면 약 10배 더 잘 맞는다고 코드에 나와 있어요.

---

### 4단계: 최근 5일 기준으로 미래 예측

```python
recent_returns = returns[-LOOK_BACK:]
pred_cum = model.predict(recent_returns.reshape(1, -1))[0]
pred_price_end = last_price * (1 + pred_cum / 100)
```

> 📌 **쉬운 설명:** 가장 최근 5일의 수익률을 모델에 넣으면 "앞으로 5일 동안 총 몇 % 변할 것 같다"는 답이 나와요. 그 비율로 오늘 종가에 곱해서 5일 후 예측 종가를 계산해요.

## 핵심 개념 한눈에 보기

| 용어 | 쉬운 설명 |
|------|---------|
| 선형 회귀 (Linear Regression) | 데이터를 직선으로 표현해서 예측하는 방법이에요. |
| 수익률 | 주가가 하루 동안 몇 % 오르거나 내렸는지를 나타내요. 예: 어제 1만원, 오늘 1만100원이면 수익률 1%예요. |
| 누적 수익률 | 여러 날의 수익률을 더한 값이에요. 5일 동안 각각 1%, -0.5%, 2%, -1%, 0.5% 변했다면 누적은 2%예요. |
| 슬라이딩 윈도우 | 데이터를 일정 크기 창으로 한 칸씩 밀면서 잘라내는 방법이에요. 연속된 패턴을 학습할 때 써요. |
| LOOK_BACK | 예측에 사용할 과거 데이터의 날 수예요. 여기서는 5일치를 써요. |
| HORIZON | 몇 일 후까지 예측할지 정하는 값이에요. 여기서는 5일 후까지 예측해요. |
| R² (R-squared) | 모델이 데이터를 얼마나 잘 설명하는지 나타내는 점수예요. 0~1 사이이고 1에 가까울수록 좋아요. |
| 종가 (Closing Price) | 그날 마지막으로 거래된 주가예요. 보통 그날을 대표하는 가격으로 써요. |
| yfinance | 야후 파이낸스에서 주가 데이터를 무료로 내려받게 해주는 파이썬 도구예요. |
| 평균 회귀 | 많이 오른 주식은 잠시 내려오고, 많이 내린 주식은 다시 오르는 경향이에요. |
| 영업일 (Business Day) | 주식 시장이 열리는 날이에요. 토·일·공휴일은 제외돼요. |
| `bdate_range` | 영업일만 포함하는 날짜 범위를 만들어주는 함수예요. |
