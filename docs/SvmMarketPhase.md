---

## 이 코드가 하는 일

병원에서 체온계와 혈압계 두 가지를 함께 보고 "열이 있다 / 없다"를 판단하는 것처럼, 이 코드는 주식 시장의 두 가지 온도계(RSI, MACD)를 함께 보고 "오르는 중(상승장)"인지 "내리는 중(하락장)"인지 SVM이라는 분류 도구로 판단합니다. 과거 주가 데이터로 훈련을 마치면, 새로운 날의 RSI와 MACD 값만 넣어도 오늘 시장이 어떤 상태인지 자동으로 알려줍니다.

### 3단계: 정답 레이블 만들기

```python

```
> 📌 **쉬운 설명:** 전체 데이터의 80%로 공부하고(학습), 나머지 20%로 시험을 봅니다(테스트). 시험 문제를 미리 공부하면 안 되듯이, 학습할 때는 테스트 데이터를 절대 보지 않습니다.

### 5단계: SVM 모델 훈련하기

> 📌 **쉬운 설명:** SVM은 RSI와 MACD 값들이 그려진 그래프에서 상승장 점들과 하락장 점들을 구분하는 **경계선**을 찾습니다. RBF 커널을 사용하면 이 경계선이 직선이 아니라 곡선으로 구불구불하게 그어지기 때문에 복잡한 패턴도 구분할 수 있습니다.

## 핵심 개념 한눈에 보기

| 용어 | 쉬운 설명 |
|------|---------|
| **SVM (서포트 벡터 머신)** | 두 그룹을 나누는 선을 찾는 분류 알고리즘. 선과 양쪽 그룹 사이의 거리(마진)를 최대한 넓게 만드는 선을 찾습니다 |
| **RBF 커널** | Radial Basis Function. SVM이 곡선 경계를 그릴 수 있게 해주는 수학 도구. 직선으로만 나눌 수 없는 복잡한 패턴에 씁니다 |
| **gamma** | RBF 커널의 "곡률"을 조절하는 값. 클수록 구불구불한 경계선이 그려집니다 |
| **RSI** | Relative Strength Index. 최근 14일 동안 올라간 힘의 비율(0~100). 70 이상=과매수, 30 이하=과매도 |
| **MACD** | Moving Average Convergence Divergence. 빠른 이동평균 - 느린 이동평균. 양수=상승 추세, 음수=하락 추세 |
| **변동성 (volatility)** | 주가가 얼마나 심하게 오르내리는지를 나타내는 값. 학교 성적으로 치면 매번 100점 받는 학생보다 50점~100점을 왔다 갔다 하는 학생이 변동성이 큰 것 |
| **서포트 벡터** | 결정 경계선에 가장 가까이 있는 데이터 점들. 이 점들이 경계선의 위치를 결정합니다 |
| **정확도 (accuracy)** | 전체 예측 중 맞힌 비율. 100개 중 70개를 맞히면 정확도 70% |
| **이동평균 (EWM)** | 최근 데이터에 더 높은 가중치를 주면서 평균을 계산하는 방법 |
| **분류 보고서** | 모델이 각 클래스(상승/하락)를 얼마나 잘 맞혔는지 정밀도, 재현율, F1 점수를 함께 보여주는 성적표 |
| **NaN 제거** | 계산이 불가능한 첫 몇 줄(지표를 계산할 과거 데이터가 부족한 날)을 없애는 작업 |
