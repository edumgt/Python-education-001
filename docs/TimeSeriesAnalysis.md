## 이 코드가 하는 일

날씨를 예측할 때 오늘 기온, 최근 1주일 평균 기온, 기온의 오르내림 패턴을 모두 살펴보는 것처럼, 이 코드는 주가를 여러 각도에서 분석합니다. 첫째로 주가의 이동평균선과 볼린저밴드로 주가 흐름을 파악하고, 둘째로 주가를 수익률로 바꾸어 "안정적인 데이터(정상 시계열)"로 만들고, 셋째로 ACF/PACF 그래프로 주가가 과거와 얼마나 관련 있는지 확인합니다. 이 세 가지 분석 결과를 한 장의 그림으로 저장합니다.

## 코드 흐름 (단계별 설명)

### 1단계: 주가 데이터 가져오기
```python
df = yf.download(TICKER, start='2020-01-01', ...)
prices = df['Close'].squeeze().dropna().values
```
> 📌 **쉬운 설명:** GS피앤엘(078935.KS)의 매일 종가를 가져옵니다. 네트워크 오류 시 수식으로 만든 가상 주가(250일치)를 사용합니다.

---

### 2단계: 단순 이동평균(SMA) 계산
```python
sma5  = np.convolve(prices, np.ones(5)  / 5,  mode='valid')
sma20 = np.convolve(prices, np.ones(20) / 20, mode='valid')
sma60 = np.convolve(prices, np.ones(60) / 60, mode='valid')
```
> 📌 **쉬운 설명:** SMA는 "최근 N일 주가의 평균"입니다. SMA5는 최근 5일 평균이라 주가 변화에 빠르게 반응하고(구불구불), SMA60은 최근 60일 평균이라 느리게 반응합니다(완만). 짧은 이동평균선이 긴 이동평균선을 위로 뚫고 올라가는 것을 "골든크로스"라 하며, 매수 신호로 봅니다.

---

### 3단계: 볼린저밴드 계산
```python
for i in range(window - 1, days):
    w = prices[i - window + 1: i + 1]
    rolling_mean.append(w.mean())
    rolling_std.append(w.std())
upper_band = rolling_mean + 2 * rolling_std
lower_band = rolling_mean - 2 * rolling_std
```
> 📌 **쉬운 설명:** 볼린저밴드는 주가 주변에 그리는 "이상 범위 표시"입니다. 20일 평균에 표준편차의 2배를 더하면 상단선, 빼면 하단선이 됩니다. 주가가 상단선을 뚫고 올라가면 "너무 많이 올랐다(과매수)", 하단선 아래로 내려가면 "너무 많이 내렸다(과매도)" 신호입니다. 음식을 너무 많이 먹으면 배탈이 나는 것처럼, 주가도 너무 빨리 오르면 조정이 올 수 있습니다.

---

### 4단계: 수익률 계산 & 정상성 검정 (ADF 테스트)
```python
returns = np.diff(prices) / prices[:-1]
adf_price   = adfuller(prices)
adf_returns = adfuller(returns)
```
> 📌 **쉬운 설명:** 주가 자체는 계속 오르거나 내리기 때문에 "비정상(non-stationary)"입니다. 오늘 주가에서 어제 주가를 빼는 "차분" 작업을 하면, 평균과 분산이 일정한 "정상(stationary)" 데이터가 됩니다. ADF 검정은 이를 수학적으로 확인하는 검사입니다. p-value가 0.05보다 작으면 "정상", 크면 "비정상"입니다.

---

### 5단계: ACF / PACF 분석
```python
plot_acf(returns,  ax=ax3, lags=30, title="자기상관 (ACF)")
plot_pacf(returns, ax=ax4, lags=30, title="편자기상관 (PACF)")
```
> 📌 **쉬운 설명:** ACF는 "오늘 수익률과 N일 전 수익률이 얼마나 비슷한가?"를 막대그래프로 보여줍니다. 막대가 파란 띠(신뢰 구간) 밖으로 나오면 유의미한 관계가 있다는 뜻입니다. 이 그래프를 보고 ARIMA 모델의 파라미터(p, q)를 결정할 수 있습니다.

---

## 핵심 개념 한눈에 보기

| 용어 | 쉬운 설명 |
|------|---------|
| **이동평균 (SMA)** | 최근 N일 주가의 평균. N이 클수록 더 느리게 반응하는 완만한 선이 됩니다 |
| **볼린저밴드** | 주가 이동평균 위아래로 그린 두 선. 주가가 이 선을 벗어나면 이상 신호입니다 |
| **표준편차 (σ)** | 주가가 평균에서 얼마나 멀리 흩어져 있는지를 나타내는 값. 클수록 변동이 심합니다 |
| **골든크로스** | 짧은 이동평균선이 긴 이동평균선 위로 올라갈 때. 매수 신호로 봅니다 |
| **데드크로스** | 짧은 이동평균선이 긴 이동평균선 아래로 내려갈 때. 매도 신호로 봅니다 |
| **정상 시계열** | 시간이 지나도 평균과 분산이 일정한 데이터. 예측 모델(ARIMA 등)에 바로 쓸 수 있습니다 |
| **비정상 시계열** | 시간에 따라 평균이나 분산이 변하는 데이터. 주가가 대표적인 예입니다 |
| **차분 (Differencing)** | 오늘 값 - 어제 값. 이렇게 하면 비정상 시계열을 정상으로 만들 수 있습니다 |
| **ADF 검정** | Augmented Dickey-Fuller Test. 데이터가 정상 시계열인지 통계적으로 검사하는 방법. p-value < 0.05이면 정상 |
| **p-value** | 검정 결과의 신뢰도. 0.05(5%)보다 작으면 "통계적으로 의미 있다"고 판단합니다 |
| **ACF (자기상관함수)** | 현재 값과 N일 전 값이 얼마나 비슷한지를 나타내는 그래프 |
| **PACF (편자기상관함수)** | ACF에서 중간 날들의 영향을 제거하고, 순수하게 N일 전과의 관계만 나타낸 그래프 |
| **lag** | "몇 일 전"을 의미합니다. lag=1은 하루 전, lag=7은 일주일 전 |
| **신뢰 구간 (파란 띠)** | ACF/PACF 그래프에서 파란 띠 안에 있는 막대는 "우연의 일치일 뿐, 진짜 관계가 없다"는 뜻 |
