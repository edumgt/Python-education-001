마법 같은 AI가 아니라, "오늘 주가는 어제·그제 주가의 영향을 받는다"는 수학 규칙을 이용해요.
예측이 끝나면 예쁜 그래프 그림을 파일로 저장해서 한눈에 볼 수 있게 해줘요.

## 코드 흐름 (단계별 설명)

### 1단계: 주가 데이터 불러오기
```python
df = yf.download('078935.KS', start='2020-01-01', ...)
prices = df['Close'].values
```
> **쉬운 설명:** 인터넷에서 GS피앤엘(078935.KS)이라는 회사의 2020년부터 오늘까지 종가(그날 마지막 거래 가격)를 가져와요. 인터넷이 안 되면 컴퓨터가 직접 비슷한 가짜 숫자를 만들어서 씁니다.

---

### 2단계: 정상성 검정 (ADF 검정)
```python
adf_raw  = adfuller(prices)
adf_diff = adfuller(np.diff(prices))
d = 1 if adf_raw[1] > 0.05 else 0
```
> **쉬운 설명:** ARIMA 모델은 주가가 "일정한 규칙"을 가져야 잘 작동해요. 이 단계에서는 지금 주가 데이터가 규칙적인지 아닌지 검사하고, 규칙적으로 만들기 위해 뺄셈(차분)을 몇 번 해야 하는지 알아내요. 시험 전에 공부할 분량이 얼마나 남았는지 확인하는 것과 비슷해요.

---

### 3단계: ARIMA 모델 설정
```python
p, d, q = 2, d, 2
model = ARIMA(prices, order=(p, d, q))
fitted = model.fit()
```
> **쉬운 설명:** ARIMA(2, 1, 2)는 세 가지 숫자로 이루어진 레시피예요. p=2는 "이틀 전까지의 주가를 참고해요", d=1은 "뺄셈을 1번 해서 정상으로 만들어요", q=2는 "이틀 전까지의 예측 실수도 반영해요"라는 뜻이에요. `model.fit()`은 이 레시피대로 실제로 요리(학습)하는 과정이에요.

---

### 4단계: 미래 22일 예측
```python
forecast_result = fitted.get_forecast(steps=22)
forecast_mean   = forecast_result.predicted_mean
conf_int        = forecast_result.conf_int(alpha=0.05)
```
> **쉬운 설명:** 학습이 끝난 모델에게 "앞으로 22 거래일(약 한 달)의 주가를 예측해봐!"라고 시켜요. 예측 결과는 중간값(예상 주가)과 함께 "95% 신뢰 구간"도 알려줘요. 이건 "실제 주가가 이 범위 안에 들어올 확률이 95%예요"라는 뜻이에요 — 마치 일기예보에서 "내일 기온은 20~25도 사이"라고 말하는 것처럼요.

## 핵심 개념 한눈에 보기

| 용어 | 쉬운 설명 |
|------|---------|
| ARIMA | "오토회귀 누적 이동평균"이라는 예측 공식. 과거 데이터의 패턴으로 미래를 예측해요 |
| p (AR 차수) | "며칠 전 주가까지 오늘에 영향을 주나"를 나타내는 숫자. p=2이면 어제·그제를 참고해요 |
| d (차분 횟수) | 주가 데이터를 "규칙적으로 만들기 위해" 빼기를 몇 번 하는지 나타내는 숫자 |
| q (MA 차수) | "며칠 전 예측 실수까지 반영할지"를 나타내는 숫자 |
| 정상성 | 주가 데이터가 일정한 평균과 흔들림(분산)을 가지는 상태. 예측 모델이 잘 작동하려면 필요해요 |
| ADF 검정 | 데이터가 정상인지 아닌지 확인하는 수학 시험. p-value가 0.05보다 작으면 정상이에요 |
| 차분 | 오늘 주가에서 어제 주가를 빼는 것. 주가를 "변화량"으로 바꿔줘요 |
| 95% 신뢰 구간 | "실제 값이 이 범위 안에 있을 확률이 95%"라는 뜻의 위아래 범위 |
| AIC / BIC | 모델이 얼마나 좋은지 점수를 매기는 방법. 숫자가 작을수록 좋은 모델이에요 |
| 종가(Close) | 그날 마지막으로 거래된 주식 가격 |
| 거래일 | 주식 시장이 열리는 날 (토·일·공휴일은 제외) |
| yfinance | 야후 파이낸스에서 주가 데이터를 자동으로 받아오는 파이썬 도구 |
