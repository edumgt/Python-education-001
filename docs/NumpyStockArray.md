# NumpyStockArray.py 코드 설명

> 한 줄 요약: NumPy로 5개 주식의 8일치 주가 표를 만들고, 수익률과 변동성을 계산해 포트폴리오를 분석합니다.

---

## 이 코드가 하는 일

5가지 물건(주식)을 가지고 있는 상인이 8일 동안 물건 값이 어떻게 변했는지 계산표를 만드는 것과 비슷해요. 매일 얼마나 올랐는지(수익률)와 가격이 얼마나 들쭉날쭉한지(변동성)를 계산하고, 100만 원을 가지고 각 물건에 어떻게 나눠 투자할지도 계산해줘요. NumPy라는 초고속 계산 도구를 사용해서 이 모든 계산을 아주 짧은 코드로 처리합니다.

## 코드 흐름 (단계별 설명)

### 1단계: 주가 데이터 표(행렬) 만들기
```python
prices = np.array([
    [100, 101, 103, 102, 104, 106, 107, 109],  # 종목 A
    [ 80,  79,  81,  82,  83,  84,  86,  87],  # 종목 B
    ...
], dtype=float)
# prices.shape → (5, 8): 5종목 × 8일
```
> 📌 **쉬운 설명:** 5개 주식 종목(A~E)의 8일치 가격을 2차원 표로 만들어요. 마치 반 친구 5명의 8번의 시험 점수를 성적표에 적어두는 것과 같아요. 세로 방향이 종목, 가로 방향이 날짜예요.

---

### 2단계: 일간 수익률 계산
```python
returns = (prices[:, 1:] - prices[:, :-1]) / prices[:, :-1]
# 수식: (오늘 가격 - 어제 가격) / 어제 가격
```
> 📌 **쉬운 설명:** "어제보다 얼마나 올랐나요?"를 비율로 계산해요. 예를 들어 어제 100원이었는데 오늘 103원이면, (103-100)/100 = 0.03 = 3% 오른 거예요. `[:, 1:]`은 2일째부터, `[:, :-1]`은 1일째부터 마지막-1일까지라서 빼면 하루씩 차이가 나요.

---

### 3단계: 평균 수익률과 변동성 계산
```python
avg_returns = returns.mean(axis=1)   # 종목별 평균 (행 방향)
volatility  = returns.std(axis=1)    # 종목별 표준편차 (행 방향)
```
> 📌 **쉬운 설명:** `axis=1`은 "옆으로(날짜 방향으로) 계산해줘"라는 뜻이에요. 각 종목의 7일치 수익률 평균과 표준편차를 구해요. 변동성이 클수록 주가가 들쭉날쭉하다는 뜻이에요 — 마치 항상 70~80점 받는 학생(안정)과 어떤 날은 30점, 어떤 날은 100점 받는 학생(불안정)의 차이와 같아요.

---

### 4단계: 포트폴리오 기대 수익률 계산 (내적)
```python
weights = np.array([0.25, 0.2, 0.2, 0.25, 0.1])  # 합계 = 1.0
portfolio_expected_return = np.dot(weights, avg_returns)
# = 0.25×A수익률 + 0.20×B수익률 + 0.20×C수익률 + ...
```
> 📌 **쉬운 설명:** 100만 원을 A에 25%, B에 20%, C에 20%, D에 25%, E에 10%씩 나눠 투자한다고 가정해요. `np.dot`은 각 비율과 수익률을 곱해서 더하는 계산이에요(내적). 마치 반 학생들의 평균 점수를 가중치 평균으로 구하는 것과 같아요.

---

### 5단계: 100만 원 기준 종목별 매수 수량 계산
```python
capital = 1_000_000          # 100만 원
last_prices = prices[:, -1]  # 8일째(마지막) 주가
allocation = capital * weights  # 종목별 투자 금액
shares = allocation / last_prices  # 살 수 있는 주식 수
```
> 📌 **쉬운 설명:** 100만 원을 가중치 비율대로 쪼갠 후, 각 종목의 현재 가격으로 나누면 몇 주를 살 수 있는지 계산돼요. 예를 들어 A주식이 109원이고 A에 25만 원을 투자한다면, 250000 ÷ 109 ≈ 2293주를 살 수 있어요.

## 핵심 개념 한눈에 보기

| 용어 | 쉬운 설명 |
|------|---------|
| **NumPy 배열 (ndarray)** | 숫자를 격자 형태로 저장하는 도구예요. 표처럼 행과 열로 된 2차원 배열도 가능해요 |
| **shape** | 배열의 크기예요. (5, 8)이면 5행 8열짜리 표라는 뜻이에요 |
| **axis** | 계산 방향이에요. `axis=0`은 위아래(종목), `axis=1`은 옆으로(날짜) 방향이에요 |
| **수익률 (Returns)** | "(오늘 가격 - 어제 가격) ÷ 어제 가격"으로 계산하는 오늘의 변화율이에요 |
| **변동성 (Volatility)** | 주가가 얼마나 들쭉날쭉한지를 나타내는 숫자예요. 클수록 위험해요 |
| **표준편차 (std)** | 숫자들이 평균에서 얼마나 멀리 퍼져있는지를 나타내요. 변동성 계산에 쓰여요 |
| **포트폴리오** | 여러 주식을 함께 모아 투자하는 것을 말해요 |
| **가중치 (Weights)** | 각 종목에 투자하는 비율이에요. 모두 더하면 1(100%)이 돼야 해요 |
| **내적 (np.dot)** | 두 배열의 같은 위치 숫자끼리 곱해서 모두 더하는 계산이에요 |
| **기대 수익률** | 투자 비율을 고려했을 때 포트폴리오 전체가 하루에 평균 몇 % 오를지 예상값이에요 |
| **리밸런싱** | 투자한 주식 수를 목표 비율에 맞게 다시 조정하는 것이에요 |
| **슬라이싱 `[:, 1:]`** | 모든 행의 2번째 열부터 끝까지 가져오라는 뜻이에요 |
