## 이 코드가 하는 일

마치 가계부에 빠진 날짜를 평균값으로 채우고, 지출 항목별로 묶어서 합계를 내는 것처럼, 이 코드는 주식 포트폴리오 표에서 비어있는 가격 정보를 자동으로 채워준 뒤 각 종목의 수익률을 계산해요. 그리고 IT, 헬스케어 같은 업종(섹터)별로 묶어서 어느 업종이 더 수익이 좋은지 분석하고 그래프로 보여줘요. Pandas는 이런 표 데이터를 다루는 데 아주 뛰어난 도구예요.

## 코드 흐름 (단계별 설명)

### 1단계: 포트폴리오 데이터 표 만들기
```python
data = {
    '종목':     ['A전자', 'B바이오', 'C에너지', 'D금융', 'E반도체', 'F플랫폼'],
    '매수가':   [68000, 42000, np.nan, 51000, 73000, 98000],  # C에너지 가격 없음!
    '현재가':   [72000, 39800, 54000, np.nan, 75500, 101000], # D금융 가격 없음!
}
portfolio = pd.DataFrame(data)
```
> 📌 **쉬운 설명:** 6개 주식 종목의 정보를 표(DataFrame)로 만들어요. 그런데 C에너지의 매수가와 D금융의 현재가가 `np.nan`(빈칸)이에요. 실제 투자 데이터에서도 이렇게 정보가 빠지는 경우가 있어요. 마치 친구 6명의 시험 성적표에 두 명의 점수가 빠진 것과 같아요.

---

### 2단계: 결측치(빈칸) 찾기
```python
null_count = portfolio.isnull().sum()
found = null_count[null_count > 0].to_dict()
# 결과: {'매수가': 1, '현재가': 1}
```
> 📌 **쉬운 설명:** 표에서 비어있는 칸이 몇 개나 있는지 세어봐요. `isnull()`은 "이 칸이 비어있나요?"라고 각 칸에 물어보는 것이고, `.sum()`은 True(비어있음)의 개수를 세는 거예요.

---

### 3단계: 결측치를 열 평균값으로 채우기
```python
for col in ['매수가', '현재가']:
    mean_val = portfolio[col].mean()        # 평균 계산 (빈칸 제외)
    portfolio[col] = portfolio[col].fillna(mean_val)  # 빈칸 채우기
```
> 📌 **쉬운 설명:** 빈 칸을 채울 때 나머지 값들의 평균을 사용해요. 예를 들어 5명의 점수 중 1명이 빠졌다면, 나머지 4명의 평균 점수로 그 칸을 채우는 거예요. `fillna()`는 "빈칸을 이 값으로 채워줘"라는 뜻이에요.

---

### 4단계: 평가금액과 수익률 계산
```python
portfolio['평가금액'] = portfolio['보유수량'] * portfolio['현재가']
portfolio['수익률(%)'] = (portfolio['현재가'] - portfolio['매수가']) / portfolio['매수가'] * 100
```
> 📌 **쉬운 설명:** 평가금액은 "지금 이 주식이 총 얼마짜리야?"예요. 보유 주식 수 × 현재 가격으로 계산해요. 수익률은 "(지금 가격 - 샀을 때 가격) ÷ 샀을 때 가격 × 100"으로 계산해요. 이 숫자가 양수면 이득, 음수면 손해예요. 마치 용돈을 저금해서 얼마나 불었는지 보는 것과 같아요.

---

### 5단계: 섹터별 그룹화 & 집계
```python
sector_summary = portfolio.groupby('섹터')[['평가금액', '수익률(%)']].mean()
```
> 📌 **쉬운 설명:** IT, 헬스케어, 에너지 등 같은 업종끼리 묶어서 평균값을 구해요. `groupby`는 마치 반 학생들을 키 순서대로 묶어서 각 그룹의 평균 키를 구하는 것과 같아요. 어느 업종의 투자가 가장 좋은 수익을 냈는지 한눈에 볼 수 있어요.

## 핵심 개념 한눈에 보기

| 용어 | 쉬운 설명 |
|------|---------|
| **Pandas DataFrame** | 엑셀처럼 행과 열로 이루어진 표를 코드로 다루는 자료구조예요 |
| **결측치 (NaN)** | 데이터가 없는 빈 칸이에요. "Not a Number"의 줄임말이에요 |
| **isnull()** | 각 칸이 비어있으면 True, 값이 있으면 False를 돌려주는 함수예요 |
| **fillna()** | 비어있는 칸을 지정한 값으로 채워주는 함수예요 |
| **groupby()** | 같은 값을 가진 행끼리 묶어서 그룹을 만드는 함수예요 |
| **섹터 (Sector)** | 주식을 업종별로 묶은 카테고리예요. IT, 헬스케어, 금융 등이 있어요 |
| **평가금액** | 지금 이 주식이 총 얼마짜리인지를 나타내는 값이에요 (보유수량 × 현재가) |
| **수익률** | 산 가격 대비 얼마나 올랐는지 퍼센트로 나타낸 것이에요 |
| **매수가** | 주식을 처음 살 때의 가격이에요 |
| **현재가** | 지금 주식의 가격이에요 |
| **twinx()** | 하나의 그래프에 두 개의 y축을 만드는 함수예요. 단위가 다른 두 데이터를 함께 그릴 때 써요 |
| **barh()** | 세로 막대 대신 가로 막대 그래프를 그리는 함수예요 |
| **포트폴리오** | 여러 주식을 모아서 한꺼번에 관리하는 나만의 주식 모음이에요 |
