# CnnCandleChart.py 코드 설명

> 한 줄 요약: 주식 캔들차트를 사진처럼 찍어서, AI가 그 사진을 보고 "내일 주가가 오를까 내릴까"를 맞히도록 훈련시키는 코드예요.

---

## 이 코드가 하는 일

사람이 주식 차트를 눈으로 보고 "아, 이 패턴이면 오를 것 같아!"라고 판단하는 것처럼, 컴퓨터도 차트 사진을 직접 보고 판단하게 만들어요.
10개짜리 캔들 차트를 작은 사진(32×32 픽셀)으로 변환한 뒤, 2D CNN(사진 인식 AI)에게 수백 장을 학습시켜요.
마치 강아지와 고양이 사진을 구분하는 AI처럼, 이 AI는 "오를 모양의 차트"와 "내릴 모양의 차트"를 구분하는 법을 스스로 배워요.

## 코드 흐름 (단계별 설명)

### 1단계: OHLC 주가 데이터 만들기
```python
df = yf.download('078935.KS', ...)
open_, high, low, close = df['Open'], df['High'], df['Low'], df['Close']
```
> **쉬운 설명:** 주식에는 하루에 네 가지 중요한 가격이 있어요. 시가(시작 가격), 고가(최고 가격), 저가(최저 가격), 종가(마지막 가격)예요. 이 네 가지를 OHLC라고 부르는데, 이 숫자들로 캔들차트를 그릴 수 있어요. 인터넷이 안 되면 컴퓨터가 가짜 데이터를 만들어요.

---

> **쉬운 설명:** 10개의 캔들을 matplotlib으로 그린 다음, 그 그림을 카메라로 찍듯이 픽셀 숫자 배열로 바꿔요. 종가가 시가보다 높으면 빨간 캔들(양봉), 낮으면 파란 캔들(음봉)으로 그려요. 최종적으로 32×32 크기의 작은 컬러 이미지가 만들어져요. 유치원생 낙서처럼 작지만, AI는 그 패턴을 인식할 수 있어요!

### 3단계: 이미지 데이터셋 만들기
```python
for i in range(0, total, 3):
    img = candle_to_image(o, h, l, c)
    images.append(img)
    labels.append(1 if close[i + N_CANDLES] > close[i - 1] else 0)
```
> **쉬운 설명:** 3일씩 건너뛰며 10개 캔들 이미지를 만들고, 그 다음 날 주가가 올랐으면 정답을 "1(상승)", 내렸으면 "0(하락)"으로 기록해요. 이렇게 수백 장의 "퀴즈 카드"를 만드는 거예요. 각 카드에는 차트 사진과 "다음 날 오름/내림" 정답이 함께 들어 있어요.

---

### 4단계: 2D CNN 모델 만들기
```python
class CNN2DCandle(nn.Module):
    def __init__(self):
        self.features = nn.Sequential(
            nn.Conv2d(3, 16, 3, padding=1),  # 이미지에서 패턴 찾기
            nn.BatchNorm2d(16), nn.ReLU(),
            nn.MaxPool2d(2),                  # 이미지 절반으로 줄이기
            nn.Conv2d(16, 32, 3, padding=1),  # 더 복잡한 패턴 찾기
            ...
        )
        self.classifier = nn.Sequential(
            nn.Linear(64 * 4 * 4, 128),
            nn.Linear(128, 2),               # 최종: 상승(1) or 하락(0)
        )
```
> **쉬운 설명:** 사람 눈처럼 이미지를 읽는 AI 뇌예요. Conv2d는 이미지를 훑으며 "여기에 빨간 막대가 여러 개 연속으로 있네!"와 같은 패턴을 찾아요. MaxPool2d는 찾은 패턴 중 가장 강한 것만 남겨서 이미지를 절반씩 압축해요. 마지막에는 "상승 또는 하락" 2개 중 하나를 선택해요.

---

### 5단계: AI 학습시키기
```python
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model2d.parameters(), lr=0.001)
for epoch in range(80):
    out = model2d(xb)
    loss = criterion(out, yb)
```

> **쉬운 설명:** AI에게 80번 반복해서 문제를 풀게 해요. 틀리면 얼마나 틀렸는지(손실)를 계산하고, 그 실수를 줄이는 방향으로 AI의 "두뇌 설정값(파라미터)"을 조금씩 수정해요. 마치 시험을 보고 채점한 뒤 틀린 부분을 복습하는 것과 같아요.

## 핵심 개념 한눈에 보기

| 용어 | 쉬운 설명 |
|------|---------|
| OHLC | 시가(Open)·고가(High)·저가(Low)·종가(Close). 하루 주가를 나타내는 4개의 숫자 |
| 캔들차트 | OHLC를 막대 모양으로 그린 그림. 빨간 막대(양봉)는 오른 날, 파란 막대(음봉)는 내린 날 |
| 양봉 | 종가 > 시가인 날. 차트에서 빨간 막대로 표시 |
| 음봉 | 종가 < 시가인 날. 차트에서 파란 막대로 표시 |
| 2D CNN | 2차원(가로×세로) 이미지에서 패턴을 찾는 AI. 사진 인식에 많이 쓰여요 |
| Conv2d | 작은 필터(돋보기)를 이미지 위로 밀면서 패턴을 감지하는 레이어 |
| MaxPool2d | 이미지를 절반 크기로 줄이면서 가장 강한 패턴 신호만 남기는 레이어 |
| BatchNorm | 학습 중 숫자가 너무 크거나 작아지지 않도록 정규화하는 장치 |
| ReLU | 음수는 0으로, 양수는 그대로 통과시키는 간단한 활성화 함수 |
| Dropout | 학습 중 AI 뉴런 일부를 임의로 꺼서 외우기(과적합)를 방지하는 기법 |
| CrossEntropyLoss | "얼마나 틀렸는지"를 계산하는 손실 함수. 분류 문제에 주로 써요 |
| Adam | 경사하강법을 영리하게 개선한 최적화 알고리즘. AI가 더 빠르게 배우게 해줘요 |
| 에폭(Epoch) | 전체 학습 데이터를 한 번 다 본 것. 80 에폭이면 80번 반복 학습이에요 |
| 정확도(Accuracy) | AI가 맞힌 비율. 0.6이면 10번 중 6번 맞혔다는 뜻 |
| 픽셀 | 이미지를 이루는 가장 작은 점. 32×32 이미지는 1024개의 픽셀로 이루어져요 |
