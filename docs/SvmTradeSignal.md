# SvmTradeSignal.py 코드 설명

> 한 줄 요약: 주식의 모멘텀(상승 힘)과 거래량 변화를 보고 "지금 사야 할까? 말아야 할까?"를 SVM 직선 경계선으로 판단하는 코드입니다.

---

## 이 코드가 하는 일

마트에서 물건을 살 때 "가격이 많이 내렸고(모멘텀이 낮음) 손님도 별로 없으면(거래량이 낮음) 지금은 좋은 시기가 아니야", "가격이 막 올라가고(모멘텀이 높음) 손님이 몰리면(거래량이 높음) 지금 사야 해!"처럼 판단하는 것과 비슷합니다. 이 코드는 주식의 모멘텀(오늘 수익률)과 거래량 변화 두 가지 숫자를 보고, SVM이 그은 **직선 경계선** 하나를 기준으로 매수(사야 할 때)와 매도/보류(팔거나 기다릴 때)를 나눕니다.

## 코드 흐름 (단계별 설명)

### 1단계: 주가 데이터 가져오기
```python
df = yf.download(TICKER, start='2020-01-01', ...)
prices_raw = df['Close'].squeeze().dropna().values
```
> 📌 **쉬운 설명:** GS피앤엘(078935.KS) 주식의 매일 종가를 인터넷에서 가져옵니다. 인터넷이 안 되면 컴퓨터가 만든 가상 주가를 씁니다.

---

### 2단계: 매매 신호 특성(feature) 만들기
```python
momentum = returns[:-1] * 100       # 오늘 모멘텀 (%)
vol_feat = vol_change[:-1]          # 오늘 거래량 변화율
next_ret = returns[1:]
y = (next_ret > 0).astype(int)      # 내일 오르면 1(매수), 내리면 0
```
> 📌 **쉬운 설명:** 두 가지 특성을 만듭니다. 첫 번째는 오늘 주가가 전날 대비 얼마나 변했는지(모멘텀), 두 번째는 거래량이 얼마나 늘거나 줄었는지입니다. 그리고 내일 실제로 올랐으면 "매수(1)", 내렸으면 "매도/보류(0)"로 정답을 적습니다.

---

### 3단계: 데이터 나누기 (7:3)
```python
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3)
```
> 📌 **쉬운 설명:** 전체 데이터의 70%로 공부하고, 30%로 시험을 봅니다. `SvmMarketPhase.py`는 8:2로 나눴지만 이 코드는 7:3으로 나눕니다.

---

### 4단계: SVM 선형 커널로 훈련하기
```python
model = SVC(kernel='linear')
model.fit(X_train, y_train)
```
> 📌 **쉬운 설명:** `SvmMarketPhase.py`는 구불구불한 곡선 경계(RBF)를 사용했지만, 이 코드는 **직선** 경계선(`linear`) 하나만 그립니다. 마치 공책에 자를 대고 줄을 하나 그어서 "선 오른쪽은 사야 할 때, 왼쪽은 기다릴 때"로 나누는 것과 같습니다.

---

### 5단계: 예측 및 정확도 평가
```python
y_pred = model.predict(X_test)
acc = accuracy_score(y_test, y_pred)
print(f"신호 분류 정확도: {acc:.4f} ({acc * 100:.1f}%)")
```
> 📌 **쉬운 설명:** 테스트 데이터에서 몇 개나 맞혔는지 계산합니다. 100개 중 65개를 맞히면 65%가 됩니다.

---

### 6단계: 결정 경계 그림 그리기
```python
def plot_signal_boundary(features, labels, clf):
    xx, yy = np.meshgrid(np.arange(x_min, x_max, step), ...)
    grid_pred = clf.predict(np.c_[xx.ravel(), yy.ravel()])
    ax.contourf(xx, yy, grid_pred, cmap=plt.cm.coolwarm, alpha=0.25)
    ax.scatter(features[:, 0], features[:, 1], c=labels, ...)
```
> 📌 **쉬운 설명:** 그래프 전체를 아주 촘촘한 격자로 나눈 뒤, 각 격자 점을 모델에 넣어서 "여기는 매수 구역이냐, 매도 구역이냐"를 판단합니다. 그 결과로 배경이 빨간색(매수) 또는 파란색(매도) 구역으로 색칠됩니다. 그 위에 실제 데이터 점을 찍으면 경계선이 어디에 있는지 한눈에 보입니다.

## 핵심 개념 한눈에 보기

| 용어 | 쉬운 설명 |
|------|---------|
| **SVM 선형 커널** | 두 그룹을 나누는 **직선** 하나를 찾는 방법. 직선으로 나눌 수 있는 간단한 문제에 씁니다 |
| **결정 경계 (Decision Boundary)** | "이쪽은 매수, 저쪽은 매도"를 나누는 기준선. SVM이 이 선의 위치를 자동으로 찾아줍니다 |
| **마진 (Margin)** | 결정 경계선과 양쪽 그룹 사이의 거리. SVM은 이 거리를 최대한 넓게 만드는 선을 찾습니다 |
| **모멘텀** | 주식의 상승하는 힘. 오늘 주가가 어제보다 얼마나 올랐는지(%). 높을수록 강하게 오르는 중 |
| **거래량 변화율** | 오늘 거래량이 평소보다 얼마나 많거나 적은지. 거래량이 급증하면 큰 변동이 올 신호일 수 있습니다 |
| **매수 신호 (1)** | "지금 사야 해!" 신호. 내일 주가가 오를 것으로 예상될 때 |
| **매도/보류 신호 (0)** | "지금은 사지 마!" 신호. 내일 주가가 내릴 것으로 예상될 때 |
| **contourf** | 그래프의 배경을 구역별로 색칠하는 함수. 경계선을 눈으로 볼 수 있게 해줍니다 |
| **meshgrid** | 그래프 전체를 촘촘한 격자점들로 채우는 함수. 배경 색칠을 위해 모든 격자점의 예측값을 계산합니다 |
| **train_test_split** | 데이터를 학습용과 테스트용으로 무작위로 나누는 함수 |
| **서포트 벡터 수** | 결정 경계를 결정하는 데 사용된 점의 개수. 이 점들만 있으면 같은 경계선을 다시 그릴 수 있습니다 |
