# yfinance 주가 데이터 정규화 비교 차트 설명

이 문서는 GS피앤엘(078935.KS) 실제 주가 데이터를 3가지 정규화 방법으로 변환한 결과를 5개 패널로 비교 시각화한 차트의 해설 가이드입니다.

---

## 정규화가 필요한 이유

AI 모델은 입력값의 크기 차이에 민감합니다. GS피앤엘 주가가 50,000원대라면 다른 저가 종목(1,000원대)과 직접 비교·학습이 어렵습니다. 정규화는 서로 다른 스케일의 데이터를 **공평한 기준**으로 맞추는 과정입니다.

---

## 패널 ①: 원본 가격 (정규화 전)

- **가로축:** 거래일 (인덱스)
- **세로축:** 실제 종가 (원)
- yfinance에서 가져온 GS피앤엘(078935.KS)의 실제 주가 원본
- 이 상태 그대로는 다른 종목이나 특성과 함께 학습하기 어렵습니다

---

## 패널 ②: Min-Max 정규화 [0, 1]

**수식:** `x' = (x - min) / (max - min)`

- **가로축:** 거래일
- **세로축:** 정규화 값 (0~1)
- **0:** 전체 기간 중 역대 최저가에 해당하는 날
- **1:** 전체 기간 중 역대 최고가에 해당하는 날
- 그래프 모양은 원본과 동일하지만 범위가 0~1로 압축됨

**역정규화 (원래 가격으로 복원):**
```
원래 가격 = x' × (max - min) + min
```
역정규화 최대 오차가 거의 0 → 정보 손실 없이 완벽하게 복원 가능

**장점:** 직관적, 역변환 쉬움  
**단점:** 이상치(극단값) 하나가 있으면 나머지가 모두 0~0.1에 몰릴 수 있음

---

## 패널 ③: Z-점수 정규화 (μ=0, σ=1)

**수식:** `x' = (x - 평균) / 표준편차`

- **가로축:** 거래일
- **세로축:** 표준편차 단위 (0 = 평균 주가)
- **+1:** 평균보다 1 표준편차 위
- **-1:** 평균보다 1 표준편차 아래
- **회색 점선 (y=0):** 전체 기간 평균 주가 기준선

**장점:** 이상치에 강건, 여러 종목을 같은 기준으로 비교 가능  
**단점:** 값 범위를 직접 해석하기 어려움 (원래 가격과 연결 불명확)

---

## 패널 ④: 로그 수익률

**수식:** `r_t = ln(P_t / P_{t-1})`

- **가로축:** 거래일
- **세로축:** 로그 수익률 (보통 ±0.05 범위 내)
- **주황 선:** 매일의 로그 수익률 (위아래로 진동)
- **회색 점선 (y=0):** 변동 없는 날 기준

**가법성(加法性):** 여러 날의 수익률을 단순히 더하면 복합 수익률이 됨 (`r_1 + r_2 = ln(P_2/P_0)`)  
**장점:** 정상 시계열, 통계 계산이 안정적, 수익률 크기 왜곡 없음  
**단점:** 절대 주가 정보 소실 (역복원 가능하지만 복잡)

---

## 패널 ⑤: 로그 수익률 분포 (히스토그램)

- **가로축:** 로그 수익률 값
- **세로축:** 해당 값이 발생한 빈도 (일 수)
- **모양이 종(bell) 모양에 가까울수록** 정규분포에 가까워 통계 모델 가정을 잘 만족함
- 실제 주가 수익률은 정규분포보다 꼬리가 두꺼운 경향 (급등·급락이 정규분포보다 더 자주 발생)

---

## 정규화 방법 선택 가이드

| 상황 | 권장 방법 |
|------|-----------|
| 딥러닝 모델 입력 (절대 가격 예측) | Min-Max |
| 딥러닝 모델 입력 (여러 종목 비교) | Z-점수 |
| 통계 분석·수익률 모델·ARIMA | 로그 수익률 |
| 이상치가 많은 데이터 | Z-점수 |

---

## 💡 종합 결론

| 방법 | 범위 | 핵심 특성 |
|------|------|-----------|
| **Min-Max** | [0, 1] | 직관적, 이상치에 취약 |
| **Z-점수** | (-∞, +∞) | 이상치 강건, 다종목 비교 용이 |
| **로그 수익률** | 작은 값 | 정상성, 통계 분석에 최적 |

정규화 방법 선택이 모델 성능에 직접 영향을 줍니다. 어떤 방법이 "항상 최고"인 것은 아니며, 분석 목적과 데이터 특성에 따라 적절히 선택해야 합니다.
