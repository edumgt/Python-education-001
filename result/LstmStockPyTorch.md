# PyTorch LSTM: 주가 시계열 예측 차트 설명

이 문서는 GS피앤엘(078935.KS)의 실제 주가 데이터를 이용해 **최근 20일 주가를 보고 다음 날 주가를 예측**하는 LSTM 신경망의 학습·평가 결과를 시각화한 차트의 해설 가이드입니다.

---

## 모델 개요

- **입력:** 최근 20일 주가 (Min-Max 정규화 후)
- **출력:** 다음 날 주가 1개
- **구조:** LSTM(hidden=32, layers=2) → Dropout(0.2) → Linear(32→1)
- **손실함수:** MSE (평균 제곱 오차)
- **학습:** 300 에폭, Adam 옵티마이저, 100 에폭마다 학습률 절반

---

## 왼쪽 패널: LSTM 학습 손실 곡선 (MSE)

- **가로축:** 학습 반복 횟수(에폭, 0~300)
- **세로축:** MSE 손실값 (낮을수록 예측이 실제에 가까움)
- **초반(0~50 에폭):** 손실이 가파르게 떨어짐 → 빠르게 배우는 구간
- **후반(200~300 에폭):** 손실이 거의 평탄해짐 → 수렴, 더 학습해도 큰 개선 없음

> 손실 곡선이 매끄럽게 우하향하면 학습이 정상적으로 진행되고 있다는 신호입니다. 갑자기 튀거나 올라가면 학습률이 너무 크거나 데이터 문제일 수 있습니다.

---

## 오른쪽 패널: 실제 주가 vs LSTM 예측

- **파란 실선:** yfinance에서 가져온 실제 종가 (테스트 구간)
- **빨간 점선:** LSTM이 20일 과거 데이터를 보고 예측한 주가
- **MAE:** 예측값과 실제값의 평균 절대 오차(원 단위)
- **RMSE:** 평균 제곱근 오차 — MAE보다 큰 오차에 더 민감

**두 선이 가까울수록** 예측이 잘 된 것입니다.

### 잘 맞추는 구간 vs 틀리는 구간

| 구간 | 이유 |
|------|------|
| **완만한 추세 구간** | LSTM이 이전 20일 평균 방향을 잘 포착 |
| **급등·급락 구간** | 갑작스러운 뉴스·이벤트는 과거 패턴에 없으므로 예측 불가 |

---

## LSTM이 RNN보다 나은 이유

일반 RNN은 오래된 기억이 점점 희미해지는 **기울기 소실** 문제가 있습니다. LSTM은 3개의 게이트(망각/입력/출력)로 장기 기억을 별도 관리하여 이를 해결합니다.

| 게이트 | 역할 |
|--------|------|
| 망각 게이트(f) | 과거 기억을 얼마나 지울지 결정 |
| 입력 게이트(i) | 새 정보를 얼마나 기억할지 결정 |
| 출력 게이트(o) | 은닉 상태로 무엇을 내보낼지 결정 |

## 💡 종합 결론

| 구분 | 내용 |
|------|------|
| 모델 | PyTorch LSTM (2-layer) |
| 입력 | 최근 20일 주가 |
| 예측 대상 | 다음 날 주가 (1일 ahead) |
| 평가 지표 | MAE, RMSE |
| 한계 | 급등·급락 같은 비연속적 변화는 예측 어려움 |

LSTM은 주가의 장기 추세를 어느 정도 포착하지만, 1일 뒤 예측은 노이즈가 많아 실전 활용에는 한계가 있습니다. 실제로는 더 긴 시퀀스, 더 많은 피처(거래량, 뉴스 등)와 함께 사용하는 것이 일반적입니다.
