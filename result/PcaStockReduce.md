# PCA 차원 축소: 6차원 주식 지표 → 2차원 시각화 차트 설명

이 문서는 가상 50개 종목의 6가지 재무·기술 지표(PER, PBR, ROE, 변동성, 수익률, 거래량)를 PCA로 2차원으로 압축하여 시각화한 차트의 해설 가이드입니다.

---

## 모델 개요

- **입력:** 50개 종목 × 6개 지표 (PER, PBR, ROE, 변동성, 수익률, 거래량)
- **방법:** PCA(주성분 분석) — 분산이 가장 큰 방향 순서로 새 축(PC) 추출
- **출력:** 6차원 → 2차원으로 압축

---

## 왼쪽 패널: PCA 설명 분산 비율

**각 주성분(PC)이 원본 정보를 얼마나 보존하는지** 보여주는 그래프입니다.

- **파란 막대 (개별 설명 분산):** 해당 PC 혼자 설명하는 정보 비율
  - PC1 막대가 가장 높음 = 가장 중요한 방향
  - PC6까지 갈수록 막대가 낮아짐
- **빨간 계단선 (누적 설명 분산):** PC1부터 해당 PC까지 합산한 정보 보존율
  - 계단이 0.9(90%) 기준선을 넘는 지점 = 그 이후 PC는 덜 중요
- **회색 점선 (90% 기준선):** 통상적으로 90% 이상 보존되면 충분하다고 봄

> PC1+PC2 두 개만으로도 전체 정보의 상당 부분을 보존합니다. 나머지 4개 PC는 노이즈에 가까운 정보를 담고 있습니다.

---

## 오른쪽 패널: 6차원 → 2차원 PCA 압축 산점도

50개 종목을 2개의 숫자(PC1, PC2)로 표현한 2D 지도입니다.

- **가로축 (PC1):** 전체 분산 중 가장 많은 정보를 담은 축
- **세로축 (PC2):** PC1 다음으로 많은 정보를 담은 축
- **점 색상:** 수익률 기준 컬러맵
  - **진한 초록:** 수익률이 높은 종목
  - **진한 빨강:** 수익률이 낮은 종목
  - **노랑:** 중간 수익률

### 무엇을 볼 수 있나?

- 비슷한 색깔의 점들이 같은 방향에 모여 있으면 → PC1 또는 PC2 축이 수익률과 연관됨
- 수익률이 높은 초록 점들이 오른쪽(PC1 큰 방향)에 몰려 있으면 → PC1이 "수익성 방향"

---

## PCA 표준화가 필요한 이유

거래량(10~500)과 PBR(0.05~3)은 단위 자체가 100배 이상 차이납니다. 표준화 없이 PCA를 하면 거래량이 PCA를 지배해버립니다. 표준화(평균=0, 표준편차=1)로 모든 지표를 같은 스케일로 맞춘 후 PCA를 수행합니다.

## 💡 종합 결론

| 구분 | 내용 |
|------|------|
| 알고리즘 | PCA (비지도 차원 축소) |
| 입력 | 6차원 재무·기술 지표 |
| 출력 | 2차원 시각화 가능한 좌표 |
| 정보 보존 | PC1+PC2로 원본의 상당 비율 보존 |
| 의의 | 고차원 데이터를 2D로 압축해 패턴·군집 시각화 |

PCA는 차원이 많아 직접 보기 어려운 데이터를 **2D 지도 위에 펼쳐서** 패턴을 발견하게 해주는 도구입니다. 딥러닝 모델의 입력 피처를 줄이거나, 고차원 데이터를 탐색적으로 분석할 때 자주 사용됩니다.
