# 선형 회귀: PER/PBR/ROE → 기대 수익률 예측 차트 설명

이 문서는 10개 가상 종목의 펀더멘털 지표(PER, PBR, ROE)로 **기대 수익률(%)** 을 선형 회귀로 예측한 결과를 산점도로 시각화한 차트의 해설 가이드입니다.

---

## 모델 개요

* **입력(X):** PER, PBR, ROE — 3가지 재무/밸류에이션 지표
* **출력(y):** 기대 수익률 (%)
* **알고리즘:** 선형 회귀 (LinearRegression) — 사이킷런 기본 구현
* **데이터:** 가상 10개 종목 (실제 시장 데이터 아님)
* **학습/테스트 분리:** 8:2 (학습 8개, 테스트 2개, random_state=42)
* **평가 지표:** MAE (평균 절대 오차, %)

---

## 모델 수식

```
기대수익률 = w0 + w1 × PER + w2 × PBR + w3 × ROE
```

각 계수(w1, w2, w3)는 학습 데이터에서 최소 제곱법(OLS)으로 자동 결정됩니다.

---

## 차트 설명: 실제 vs 예측 수익률 산점도

### 가로축 (X축) — 실제 기대 수익률 (%)

데이터에 입력된 실제 기대 수익률입니다. 오른쪽으로 갈수록 실제 수익률이 높은 종목입니다.

### 세로축 (Y축) — 예측 기대 수익률 (%)

PER/PBR/ROE를 보고 모델이 계산한 예측값입니다. 위로 갈수록 모델이 더 높은 수익률을 예측한 종목입니다.

### 파란 점 — 종목 데이터 포인트

점 하나가 가상 회사 한 곳의 실제/예측 쌍입니다. 전체 10개 종목이 모두 표시됩니다.

### 빨간 점선 — 완벽한 예측선 (y = x 대각선)

예측값과 실제값이 완전히 일치할 때 점이 놓이게 되는 45° 대각선입니다. 점들이 이 선에 가까울수록 모델 예측이 정확함을 의미합니다.

---

## 예측 결과 예시

신규 종목 입력값: **PER=9.2, PBR=0.95, ROE=14.8** 인 경우 모델이 예측한 기대 수익률이 콘솔에 출력됩니다.

---

## 계수 해석 가이드

| 지표 | 일반적 의미 |
|------|------------|
| PER (주가수익비율) | 낮을수록 저평가 — 보통 수익률 예측에 음(−) 계수 |
| PBR (주가순자산비율) | 낮을수록 저평가 — 보통 음(−) 계수 |
| ROE (자기자본이익률) | 높을수록 수익성 우수 — 보통 양(+) 계수 |

> **주의:** 10개 샘플로 학습한 단순 예시이므로 계수의 크기와 부호는 실제 시장과 다를 수 있습니다.
