# Transformer Attention: 주가 방향 분류 차트 설명

이 문서는 GS피앤엘(078935.KS) 실제 주가 데이터로 **과거 30일 수익률 시퀀스를 보고 다음 날 상승/하락**을 Transformer Self-Attention으로 분류한 결과를 4패널로 시각화한 차트의 해설 가이드입니다.

---

## 모델 개요

- **입력:** 과거 30일 일별 수익률 시퀀스
- **출력:** 다음 날 상승(1) / 하락(0)
- **구조:** Linear 투영 → Positional Encoding → TransformerEncoder(Multi-Head Attention) → Global Average Pooling → 분류기
- **d_model=16, nhead=4, num_layers=2**

---

## 패널 1 (좌상): 학습 손실

- **가로축:** 에폭 (0~120)
- **세로축:** Cross-Entropy 손실
- 초반 빠르게 떨어진 후 완만하게 수렴

---

## 패널 2 (우상): 학습 정확도

- **파란선 없음 → 빨간선:** 에폭이 진행됨에 따라 학습 정확도 상승
- **회색 점선 (0.5):** 동전 던지기와 동일한 무작위 기준선
- **제목의 테스트=N:** 최종 테스트 데이터에서의 정확도

> 학습 정확도가 0.5를 의미 있게 넘어야 모델이 무언가를 배운 것입니다.

---

## 패널 3 (우상): 테스트 샘플별 상승 예측 확률

- **가로축:** 테스트 샘플 번호 (최대 60개)
- **세로축:** 모델이 계산한 상승 확률 (0~1)
- **빨간 막대:** 상승 확률 ≥ 0.5 → 상승 예측
- **파란 막대:** 상승 확률 < 0.5 → 하락 예측
- **검정 점선 (0.5):** 상승/하락 분류 기준선

> 막대 높이가 다양하게 분포해야 좋은 모델입니다. 모든 막대가 같은 높이면 모델이 한쪽 방향으로만 찍고 있다는 뜻(모드 붕괴)입니다.

---

## 패널 4 (하단 전체): Self-Attention 가중치 히트맵 ★ 핵심

이 차트가 Transformer 실습의 핵심입니다.

- **가로축 (Key 위치):** 모델이 참조하고 있는 날짜 (0~29, 0=30일 전)
- **세로축 (Query 위치):** 모델이 현재 보고 있는 날짜
- **색상:** 밝을수록(노랑/흰색) 해당 두 날짜 사이의 Attention 가중치가 높음

### 읽는 방법

- 세로축의 특정 행(Query 날짜)을 따라 가로로 보면 → "이 날짜가 어느 날짜에 주의를 기울였는지" 알 수 있음
- **대각선이 밝으면:** 가까운 날짜끼리 서로 주목 → 단기 패턴 중심 학습
- **특정 열만 밝으면:** 모든 날짜가 그 특정 날을 주목 → 그 날이 예측에 매우 중요한 날임을 학습

### Attention 메커니즘 비유

> 책을 읽을 때 중요한 단어에 밑줄을 긋듯이, Transformer는 30일 시퀀스 중 예측에 중요한 날짜에 높은 가중치(밑줄)를 자동으로 부여합니다. RNN이 순서대로 읽는 것과 달리 Transformer는 모든 날짜를 동시에 보며 중요한 관계를 찾습니다.

| 구성 요소 | 역할 |
|-----------|------|
| Q (Query) | 지금 예측하려는 것: "다음 날이 어떻게 될까?" |
| K (Key) | 과거 각 날의 특성 요약: "나는 이런 날이었어" |
| V (Value) | 실제로 전달할 정보: "내 정보를 이 비율로 줄게" |

| 구분 | 내용 |
|------|------|
| 모델 | Transformer (Multi-Head Self-Attention) |

| 예측 | 다음 날 상승/하락 |
| 핵심 개념 | 날짜 간 중요도를 학습하는 Attention |
| 차별점 | RNN과 달리 모든 날짜를 동시에 참조 |

Transformer는 자연어 처리(ChatGPT 등)에서 혁신을 이끈 아키텍처입니다. 주가 시계열에도 적용되지만, 학습 데이터가 충분하지 않으면 RNN보다 성능이 낮을 수 있습니다. Attention 히트맵을 통해 모델이 어느 날을 중요하게 보는지 해석할 수 있다는 것이 큰 장점입니다.
