# 시계열 윈도우 생성 & LSTM 주가 예측 차트 설명

이 문서는 GS피앤엘(078935.KS) 실제 주가 데이터를 **윈도우=20일, 예측=5일 후** 설정으로 슬라이딩 윈도우 데이터셋을 만들고 LSTM으로 예측한 결과를 4패널로 시각화한 차트의 해설 가이드입니다.

| 항목 | 값 |
|------|----|
| 종목 | GS피앤엘 (078935.KS) |
| 윈도우 크기 | 20일 (과거 20일치로 예측) |
| 예측 기간 | 5일 후 가격 |
| 스텝 크기 | 1 (매일 1칸씩 이동) |

---

## 패널 1 (좌상): 윈도우 샘플 5개

- 전체 데이터에서 균등 간격으로 추출한 5개의 20일짜리 윈도우를 겹쳐서 표시
- **가로축:** 시퀀스 위치 (0~19, 0=20일 전, 19=가장 최근)
- **세로축:** Min-Max 정규화된 주가 (0=역대 최저가, 1=역대 최고가)
- **각 선의 모양:** AI가 "이런 패턴이면 5일 후에 어떻게 될까?" 를 학습하는 입력의 예시

> 모든 윈도우가 다른 모양을 가지는 것이 정상입니다. AI는 이 다양한 모양들에서 공통적인 예측 패턴을 찾아냅니다.

---

## 패널 2 (우상): LSTM 학습 손실 (MSE)

- **가로축:** 학습 에폭 (0~160회)
- **세로축:** MSE 손실 (낮을수록 예측이 실제에 가까움)
- **초반 급격한 하락:** 빠르게 기본 패턴을 학습하는 구간
- **후반 완만한 하락:** 미세하게 정확도를 높이는 구간

---

## 패널 3 (좌하): 예측 vs 실제

- **파란 실선:** 실제 종가 (테스트 구간 최대 100개 샘플)
- **빨간 점선:** LSTM이 예측한 5일 후 가격
- **MAE / RMSE:** 평균 절대 오차 / 평균 제곱근 오차 (원 단위)

### 예측의 의미

이 모델이 예측하는 것은 "오늘 기준 **5일 뒤** 주가"입니다. 1일 뒤보다 5일 뒤는 불확실성이 더 크지만, 단기 노이즈를 어느 정도 평균화합니다.

### 두 선이 가까운 구간 vs 멀어지는 구간

| 구간 | 이유 |
|------|------|
| 두 선이 비슷하게 움직임 | 추세가 일정해 LSTM이 잘 포착 |
| 두 선이 크게 벌어짐 | 급등·급락 이벤트는 과거 패턴에 없음 |

## 💡 종합 결론

| 구분 | 내용 |

| 예측 | 5일 후 주가 |
