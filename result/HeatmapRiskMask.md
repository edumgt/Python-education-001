# 히트맵 & 마스킹: 수익률 고위험 구간 탐지 차트 설명

이 문서는 20일 × 20종목 가상 수익률 행렬을 히트맵으로 시각화하고, 절대 수익률이 2%를 초과하는 고위험 구간을 자동으로 탐지·강조한 차트의 해설 가이드입니다.

---

## 데이터 구성

- **행(세로):** 거래일 번호 0~19 (20일)
- **열(가로):** 종목 번호 0~19 (20개 종목)
- **각 셀 값:** 해당 날짜 해당 종목의 수익률(%)
- **고위험 기준:** 절대값 > 2.0% (급등 또는 급락)

---

## 패널 1: 원본 수익률 맵

초록색과 빨간색으로 이루어진 색상 지도입니다.

- **초록 진할수록** → 해당 날짜에 해당 종목이 크게 **올랐음**
- **빨강 진할수록** → 해당 날짜에 해당 종목이 크게 **내렸음**
- **노랑/연한 색** → 수익률이 거의 0에 가까운 보합 상태

> 마치 달력에 날씨를 색깔로 표시한 것처럼, 종목과 날짜 두 축으로 수익률을 한눈에 볼 수 있습니다.

---

## 패널 2: 고위험 마스크 (이진 위험 표시)

흰색과 검정색 두 가지 색만 사용한 단순한 지도입니다.

- **흰색 셀:** 해당 날짜에 해당 종목이 ±2% 이상 크게 움직인 **위험 구간**
- **검정 셀:** ±2% 미만으로 움직인 **정상 구간**

이처럼 조건을 만족하는 셀을 1, 나머지를 0으로 표시하는 것을 **마스킹(Masking)** 이라고 합니다. 이미지 처리나 이상 탐지에서 자주 쓰이는 기법입니다.

---

## 패널 3: 위험 구간 강조 히트맵

패널 1과 같은 색상 체계지만, 위험 구간(|수익률| > 2%)의 값을 ±3.0으로 강제 설정하여 색 대비를 극대화한 버전입니다.

- 패널 1에서 연하게 보이던 위험 구간이 **훨씬 진하게** 표시됩니다
- 위험한 날/종목 조합을 한눈에 식별하기 쉽습니다

---

## 💡 종합 결론

| 구분 | 내용 |
|------|------|
| 기법 | 히트맵 시각화 + 이진 마스킹 + 강조 처리 |
| 데이터 | 가상 20일 × 20종목 수익률 행렬 |
| 위험 기준 | 절대 수익률 > 2.0% |
| 의의 | 수백 개 데이터를 색으로 압축해 이상 구간을 즉시 파악 |

이 실습의 핵심은 **"수치 데이터를 색깔 지도로 바꾸면 이상 구간을 눈으로 즉시 발견할 수 있다"** 는 것입니다. 실제 리스크 관리에서는 이런 히트맵으로 특정 날짜에 여러 종목이 동시에 급락하는 상관 위험을 감지하는 데 활용됩니다.
