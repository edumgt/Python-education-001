# 신경망 역전파(Backpropagation) 직접 구현: 주가 예측 차트 설명

이 문서는 GS피앤엘(078935.KS) 실제 주가 데이터로 **최근 5일 주가 → 다음 날 주가** 를 예측하는 2층 신경망을 PyTorch 없이 NumPy만으로 직접 구현하고, 그 학습·평가 결과를 시각화한 차트의 해설 가이드입니다.

---

## 모델 구조

```
입력층(5) → 은닉층(8, sigmoid) → 출력층(1)
```

- **입력:** 최근 5일 주가 (Min-Max 정규화 후)
- **은닉층:** 8개 뉴런, 활성화 함수 sigmoid
- **출력층:** 다음 날 주가 1개 (선형)
- **손실함수:** MSE (평균 제곱 오차)
- **학습률:** 0.05, **에폭:** 2,000회

---

## 왼쪽 패널: 학습 손실 변화 (MSE)

- **중앙 텍스트:** 2,000 에폭 후 최종 손실값 표시
- **"처음엔 많이 틀려요"** → 초기 가중치가 무작위라 오차가 큼
- **"오차가 많이 줄었어요!"** → 2,000회 반복 후 오차가 크게 감소

> 역전파(Backpropagation)는 마치 오답 노트를 쓰는 것과 같습니다. 틀린 정도(손실)를 계산하고, 그 오류를 출력층에서 입력층으로 거슬러 전달하면서 가중치를 조금씩 수정합니다. 이 과정을 2,000번 반복하면 오차가 줄어듭니다.

### 역전파 수식 (직접 구현한 내용)
```
순전파: z1 = X @ W1 + b1,  a1 = sigmoid(z1),  y_pred = a1 @ W2 + b2
역전파: dW2 = a1ᵀ @ d_y_pred,  dW1 = Xᵀ @ (d_a1 * sigmoid'(a1))
가중치: W -= lr * dW
```

## 오른쪽 패널: 실제 주가 vs 예측 주가

- **파란 실선:** yfinance에서 가져온 실제 종가 (테스트 구간)
- **빨간 점선:** 신경망이 직전 5일을 보고 예측한 다음 날 주가
- **하단 텍스트:** 테스트 MAE (원 단위) 및 "두 선이 가까울수록 좋음" 안내

### 예측 특성

| 구간 | 해석 |
|------|------|
| **추세 유지 구간** | 예측선이 실제선을 잘 따라가는 구간 |
| **급격한 변화 구간** | 5일치 데이터에 없는 변화라 놓치는 구간 |

> 이 모델은 외부 라이브러리 없이 행렬 곱셈과 미분만으로 신경망 전체를 구현했다는 데 의의가 있습니다. LSTM이나 PyTorch가 내부적으로 하는 일을 손으로 펼쳐 보인 것입니다.
