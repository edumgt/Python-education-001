# 바닐라 RNN(BPTT): 주가 방향 예측 차트 설명

이 문서는 GS피앤엘(078935.KS) 실제 주가 데이터를 이용해 **직전 10일 수익률 시퀀스로 다음 날 주가 상승/하락 방향**을 예측하는 바닐라 RNN을 NumPy로 직접 구현하고, 그 결과를 시각화한 차트의 해설 가이드입니다.

---

## 모델 개요

- **입력:** 직전 10일 일별 수익률 시퀀스
- **출력:** 다음 날 상승(1) / 하락(0)
- **구조:** 바닐라 RNN (hidden=16) + 출력층
- **학습:** BPTT(시간을 통한 역전파), BCE 손실, 600 에폭

### RNN 핵심 공식
```
h_t = tanh(Wx·x_t + Wh·h_{t-1} + b)   ← 은닉 상태 업데이트
y_t = sigmoid(Wy·h_t + by)              ← 상승 확률 출력
```
이전 시점 은닉 상태 `h_{t-1}` 를 현재에 재사용하는 것이 RNN의 핵심 — "기억"

---

## 왼쪽 패널: RNN 학습 손실 (BCE Loss)

- **가로축:** 학습 에폭 (0~600)
- **세로축:** Binary Cross-Entropy 손실 (낮을수록 예측이 정확)
- **주황 점선 (ln2 ≈ 0.693):** 완전한 무작위 예측(동전 던지기)과 동일한 손실 기준선

### 구간 해석

| 구간 | 의미 |
|------|------|
| 초반 — 손실이 0.693 근처 | 아직 무작위 수준, 학습 시작 |
| 중반 — 손실이 0.693 아래로 내려감 | 동전 던지기보다 나은 예측 시작 |
| 후반 — 손실이 거의 평탄 | 수렴, RNN의 구조적 학습 한계 도달 |

> 바닐라 RNN은 시퀀스가 길어질수록 초반 정보가 희미해지는 **기울기 소실** 문제가 있어 성능에 한계가 있습니다. LSTM이 이 문제를 해결합니다.

---

## 오른쪽 패널: 예측 방향 막대 차트

테스트 샘플 40개에 대해 RNN이 예측한 방향을 막대로 표시합니다.

### 막대 색상 — 예측 방향

- **빨간 막대:** 해당 날 다음 날이 **상승**할 것으로 예측
- **파란 막대:** 해당 날 다음 날이 **하락**할 것으로 예측

### 막대 위 원형 점 — 정오답 표시

- **금색(노란) 점:** 예측이 **맞은** 샘플
- **검정 점:** 예측이 **틀린** 샘플

### 정확도 해석

- **50% 기준:** 동전 던지기와 동일한 확률
- 정확도가 50%에 가까우면 무작위 수준
- 정확도가 50%를 크게 넘으면 모델이 의미 있는 패턴을 학습한 것

| 모델 | 바닐라 RNN (NumPy 직접 구현) |

| 예측 | 다음 날 상승/하락 방향 |
| 한계 | 기울기 소실 — 오래된 기억이 희미해짐 |
| 개선 방향 | LSTM (장기 기억 셀 상태 별도 관리) |

바닐라 RNN은 **"과거를 기억하지만 오래된 기억은 잊어버리는"** 구조적 한계가 있습니다. 이 실습은 그 한계를 확인하고, LSTM이 왜 필요한지 동기를 이해하기 위한 과정입니다.
